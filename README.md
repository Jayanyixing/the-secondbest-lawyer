# the-secondbest-lawyer

北京律师实务 Skill

面向北京执业律师的法律工作技能，覆盖中国大陆民商事、刑事案件及企业法律顾问。默认关注北京规则；具体案件的管辖、法律适用和程序要求按事实核验。

## 工作模块

| 模块 | 主要用途 |
|---|---|
| 总控与任务分派 | 受理、选择工作模块、整合成果与交接 |
| 法律法规与案例检索 | 官方原文、法律效力与适用时点、正反类案 |
| 民商事诉讼策略与文书 | 请求权、抗辩、诉讼与相关仲裁文书 |
| 刑事辩护与刑事文书 | 分阶段工作、会见阅卷准备、辩护与代理意见 |
| 证据梳理与庭审准备 | 证据矩阵、质证、发问及庭审提纲 |
| 合同审核与日常法律顾问 | 合同修订、可替换条款与咨询答复 |
| 企业信息与法律尽职调查 | 主体股权核验、调查底稿、法律尽调报告 |
| 财产线索、保全与执行 | 合法线索、权属核实路径与措施方案 |
| 律所投标与法律服务方案 | 招标响应、真实资质业绩、方案及报价核对 |
| 案件流程与公检法联络信息 | 节点、期限、公开办公电话及办事路径 |
| 法律质量与引用核验 | 事实、法条案例、金额、期限和交付完整性 |

## 文件结构

```text
the-secondbest-lawyer/
├── SKILL.md                 技能入口、任务识别和共用规则
├── agents/openai.yaml       显示名称及默认调用提示
└── references/              11个业务模块、官方来源、交接模板和验收场景
```

入口文件：[the-secondbest-lawyer/SKILL.md](the-secondbest-lawyer/SKILL.md)。各模块按需要加载，重复规则集中维护。

## 使用

将 `the-secondbest-lawyer` 完整文件夹放入运行环境支持的技能目录，再通过技能名称选择或显式调用。Codex 的技能结构与调用方式见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

示例：

```text
请使用 $the-secondbest-lawyer，站在供应商立场审查这份合同，
给出高风险条款、可直接替换的文本，以及需要补充核实的问题。
```

也可以要求起草诉讼文书、梳理证据、设计刑事分阶段工作计划、制作法律尽调报告或律所标书。提供已有材料、代理立场、程序阶段、关键日期和希望交付的成果；缺失的重要信息会明确标注。

## 检索与工具

技能规定了国家法律法规数据库、中国裁判文书网、人民法院案例库及北京官方来源的使用方式，并要求核对法律适用时点、具体条款、案例差异与原始出处。

这是指令型技能。联网检索、受权限限制的案件资料、文件生成、正式提交和持续提醒，需要相应工具、合法权限及实际执行结果。技能不自动获得数据库权限，也不自行常驻运行。

## 核验

技能格式、内部文件引用和压缩包结构已检查。`references/acceptance-scenarios.md` 提供人工试用场景；未开展真实案件准确率评测。正式成果由承办律师结合原始材料与实际委托复核。
