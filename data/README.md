# 本地法条库（L1）

`law.sqlite` 由 `tools/lawdb.py` 生成。仓库自带 **42 部核心法、5807 条**，开箱可检索。

**来源分两类，务必看清**：

- `官方复核：已核`——3 部，直接从中国人大网当期页面取得原文并核过条数；
- `未核`——39 部，来自维基文库转载，**版本未必为最新修正**。引用前必须按 `references/citation.md` 打开官方原文回读，转载件不能直接充当“已核”依据。

完整清单见 [`CORPUS.md`](CORPUS.md)。

## 换成官方件（推荐）

用官方下载的同一名称文件重新导入即可按法名覆盖：

```bash
python3 tools/lawdb.py import 民法典.docx --name 中华人民共和国民法典 \
  --issuer 全国人民代表大会 --publish 2020-05-28 --effective 2021-01-01 \
  --url https://flk.npc.gov.cn/... --official-check 已核 --note "官方原件"
```

覆盖后 `stats` 里的来源渠道与复核状态会同步更新。

## 加一部法（3 分钟）

1. **下载**：打开 [国家法律法规数据库](https://flk.npc.gov.cn/) 或 [中国人大网](http://www.npc.gov.cn/)，检索法规 → 用页面「下载」取 Word/HTML，或浏览器「另存为」。
2. **放进** `data/sources/`。
3. **登记**：在 `data/manifest.json` 加一条：

```json
{
  "file": "data/sources/中华人民共和国民法典.txt",
  "name": "中华人民共和国民法典",
  "issuer": "全国人民代表大会",
  "publish": "2020-05-28",
  "effective": "2021-01-01",
  "url": "https://flk.npc.gov.cn/...",
  "official_check": "已核",
  "channel": "官方页面",
  "fetched_at": "2026-11-08"
}
```

4. **入库**：`python3 tools/lawdb.py seed`

## 为什么不直接抓

官方站点普遍反爬：`flk` 的接口已改为前端渲染（所有 `/api/*` 返回同一 SPA），人大网历史文章页一律 302 到首页，法院转载站 403、最高法公报 502。批量抓取既不稳定也不合规。**下载一次、本地长期复用**是唯一可持续的路子。

这也是为什么仓库里只有 3 部当期法律：只有当期发布的页面还能稳定取到原文，历史法规需要你在浏览器里下载一次。

## 校验

```bash
python3 tools/lawdb.py verify   # 比对磁盘文件哈希，被替换或修订即报警
```

法规文本不受著作权保护（法律、法规不属于《著作权法》保护对象），可以随仓库分发；但商业库导出的文件受订阅许可限制，不要提交进仓库。
