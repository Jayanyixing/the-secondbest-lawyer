# 盲评（10 案，2026-11-09）

测的是「给定事实与材料边界，技能能否把结论、依据、时点、风险、边界写对」，不是测文采。

## 方法

- **样本**：最高人民法院两批典型案例各 5 件（劳动争议 5、虚假诉讼逃废债 5），均已生效并有官方裁判理由。
- **盲法**：`blind/C01–C10.md` 只给事实与材料边界（无案号、无结论、无裁判理由）；`sealed/C01–C10.md` 存官方裁判理由与典型意义，跑测期间移出工作区，评分完成后才比对。`sealed/` 不入库，避免下次跑测泄题。
- **隔离**：10 个独立上下文并行作答，禁网、禁编案号、只准用 `tools/lawdb.py` 与本地卡片库，条号用中文数字。
- **产出**：`runs/C01–C10.md`，固定六节（争议焦点／结论预判与把握度／法律依据（逐字摘录＋回读状态）／时点适用／不利面与对方最强攻击／材料缺口与待核）。
- **评分**：`scores.csv`，6 维 0–3 分，任一维为 0 或出现编造引用记「阻断」。`python3 tools/eval_score.py eval/scores.csv`。

10 案中 7 案结论方向与官方一致（C01、C03、C05、C06、C07、C08、C09），3 案有实质缺口：

- **C02 过度拒答（交付可用 1）**：把「劳动人事」整块判为范围外，只答程序不答实体。根因是 `references/scope.md` 那行写成「可做的最小子集：前置程序与管辖」，被读成不许碰实体 → 已改为「规则适用与结果预判在范围内，排除的是精确测算与终局定性」。
- **C04 漏主线（2）**：抓到了「同行业不等于竞争关系」，漏掉本案真正的规则——竞业限制义务范围应限于劳动者知悉的关联方商业秘密（本案限于两款药物）。
- **C10 误工费误判（2）**：判「误工费难支持」，官方实际支持 12,060 元。

## 限制（读结果前必看）

- **引用可追溯一律封顶 2 分**：本批评测禁网，全部引用只能标「摘录来自本地库」，回读率 0%（门禁要求 ≥90%）。这是评测设置导致，不是技能缺陷；联网条件下该项应重新测。
- 样本 10 件、单一评分人，分数是定性判断的量化记录，不是统计结论。
- 「交付可用 1」的 C02 属于真实缺陷，已修；修改后未重跑该案。
