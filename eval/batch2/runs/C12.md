# C12 信息网络买卖合同纠纷 · 策略简报〔自查〕

> 案由：信息网络买卖合同纠纷｜材料：最高法发布稿摘编事实，无合同、订单、往来记录原件｜全部日期、金额、案号、法院均未披露，本稿不补造。

## 一、争议焦点

1. **除外商品要件**：涉案女士手提包是否属于《消费者权益保护法》第二十五条第一款四项法定除外商品（定作、鲜活易腐、数字化商品、报刊）——从商品属性看应属否定。
2. **约定排除要件（核心）**：店铺页面标注“不支持七日无理由退货”，能否构成第二十五条第二款“根据商品性质**并经消费者在购买时确认**不宜退货”。该款为双重要件：①商品性质确不宜退货；②购买时经消费者确认。经营者仅完成“标注”，两项要件均未证明〔N-01〕。
3. **标注条款的效力**：单方拟定的“一律不支持无理由退货”属格式条款，落入第二十六条第二、三款及《民法典》第四百九十六条、法释〔2022〕8号第一条第五项的评价范围，可主张不成为合同内容或无效〔N-02｜N-03｜N-05〕。
4. **解除与后果**：七日内提出退货申请即行使法定解除权（《民法典》第五百六十五条），后果为恢复原状——退货退款（第五百六十六条）〔N-06｜N-07〕，并以“商品完好”为条件（第二十五条第三款）。
5. **举证责任**：主张“性质不宜退货”的是经营者，其应就商品性质、价值大幅贬损或重大损失举证（民诉法解释第九十条）〔N-08〕。

## 二、结论预判

- **立场假设**：代理胡某（消费者，原告，请求判令退货退款）。未指定立场，按起诉方即消费者立场出简报；文末附镜像判断。
- **把握度**：较高，估计七至八成获支持退货退款，其中全额退款为主、折价退款为次。
- **判断支点**：本材料事实与最高人民法院 2025-06-16 发布的网络消费民事典型案例第 2 件（胡某与韩某等信息网络买卖合同纠纷案）基本案情逐句对应，该案裁判结果支持退货退款，裁判理由正是“标注了但不等于性质不宜退货、亦未举证贬损”，同型度极高〔C-01｜分析推断：同一案，发布稿已化名〕。
- **主要变量**（按影响力排序）：① 商品是否“完好”（已使用、吊牌剪除、包装缺失将直接压缩请求）；② 收到商品之日与申请退货之日的凭据是否齐备（七日期间）；③ 下单流程中是否存在针对该商品个别化的“确认”动作；④ 被告是否店铺注册经营者（主体抗辩）；⑤ 货款金额与运费承担。
- **镜像判断**：若代理韩某，法律层面“页面标注即排除退货权”难以成立（同型案例已作否定评价），可争空间集中在“商品完好”“七日期间已过”“消费者已实际使用致贬值”三项事实抗辩，目标是驳回或折价，而非全胜。

## 五、不利面与对方最强攻击

1. **“购买时已确认”抗辩（最强）**：韩某会主张页面已显著标注、下单时已勾选同意，第二十五条第二款的“确认”要件已满足。应对：该款以“根据商品性质”为前提，确认不能替代性质审查；且确认须针对该具体商品、个别化提示，统一页面标注属格式条款，依第二十六条第三款无效〔N-02〕、依法释〔2022〕8号第一条第五项无效〔N-03〕；举证责任在经营者〔N-08〕。
2. **商品完好抗辩**：第二十五条第三款要求“商品应当完好”。若胡某已使用、剪吊牌、丢弃包装或配件，韩某可主张不满足退货条件或要求折价。应对：以法释〔2022〕8号第三条主张必要拆封查验不等于不完好〔N-04〕；同时以收货照片、开箱视频、寄回前状态固定“完好”，把举证压力推回对方。
3. **七日期间抗辩**：若以物流签收日为起算点，而平台申请记录显示已逾七日（含系统延迟、客服协商占用时间），法定解除权即消灭。应对：调取平台申请时间戳与客服聊天记录，证明首次申请在七日内；协商过程不构成期间中断，但可证明及时主张。
4. **主体抗辩**：韩某可能主张自己非实际经营者（账号出借、代运营、店铺已转让），请求驳回对其个人的诉请。应对：核店铺公示的营业执照与平台披露信息，必要时追加注册经营者与实际经营者；此点属程序补正，不影响实体走向。
5. **部分支持风险**：法院可能认定退货权成立但商品已贬值，判令退货同时折价补偿，或仅退货款不退运费（第二十五条第三款：退回商品运费由消费者承担）。应预先向当事人说明“全额退款”非必然结果。
6. **类案效力被稀释**：C-01 为典型案例，对方可主张其非指导性案例、无拘束力，且个案商品性质不同。应对：不以“应参照”立论，而以该案说理路径（性质举证＋贬损举证）作为要件事实的证明标准。
