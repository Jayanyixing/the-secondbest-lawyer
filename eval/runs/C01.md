# C01 策略简报

**结论**：建筑公司完全免责把握度低；可争取剔除一次性工伤医疗补助金、一次性伤残就业补助金，并核减基数、抵扣已付款，部分减损把握度中。
**最紧迫**：先核仲裁裁决书类型与送达日——若属终局裁决，用人单位无起诉权，须按第49条在收到裁决书30日内向中院申请撤销；法院不予受理的，另可依解释（一）第18条自不予受理裁定书30日内申请。逾期裁决生效（待核）。
**最大缺口**：无仲裁裁决书、参保证明、工资与已付款凭证，责任范围与金额均无法定论。

## 一、争议焦点

1. **程序先决**：本案仲裁裁决是否终局裁决？建筑公司向基层法院起诉，是否属于法院受理范围？
2. **责任范围**：工伤认定已作出并明确建筑公司承担工伤保险责任，在生效判决确认无劳动关系的前提下，建筑公司应承担的待遇项目是否包括一次性工伤医疗补助金、一次性伤残就业补助金、停工留薪期工资及医疗费？
3. **金额**：各项待遇的基数（本人工资）、所在省标准、基金支付与单位支付的划分、已付款抵扣。
4. **追偿**：建筑公司赔付后向刘某追偿能否另诉，与本案责任认定如何衔接。

## 二、结论预判（我方主张能否成立、把握度、主要变量）

按我方代理建筑公司（原告）分析：

- **全部不支付：弱。** 工伤认定决定已作出且载明建筑公司承担工伤保险责任；生效判决确认无劳动关系，恰是违法转包用工责任类型的典型事实，不构成免责事由。以“无劳动关系”作唯一抗辩，难以成立。
- **部分减损：中。** 可争三点：(1) 一次性工伤医疗补助金、一次性伤残就业补助金以“劳动、聘用合同期满终止，或者职工本人提出解除”为前提，本案无劳动关系、材料未见张某提出解除，前提缺失（可争，但类案存在分歧）；(2) 已参保的，一次性伤残补助金、一次性工伤医疗补助金、医疗费由基金支付，单位主要承担停工留薪期工资和一次性伤残就业补助金；(3) 本人工资按受伤前12个月平均月缴费工资计算；未参保或无缴费记录的，基数按工资记录核定；已付款应抵扣，生活自理障碍未达级则无生活护理费。
- **程序驳回起诉：无法判断。** 取决于裁决书类型：载明终局，或未载明但整案属社会保险争议的，基层法院应不予受理、已受理的裁定驳回起诉；同一裁决同时含终局与非终局事项的，按非终局处理，本案可继续审理。非终局的，依第50条应在收到裁决书15日内起诉，本案已起诉，需核是否在期内。
- **主要变量**：裁决书类型与送达日；是否按项目参保；张某是否及何时提出解除；本人工资基数；已付款金额；所在省补助金标准。
- **建议路径**：先核程序（裁决书），再定实体（参保＋项目＋基数），同步评估与张某和解及对刘某追偿。

## 四、对方最强攻击与化解（≥3 条）

1. **程序攻击：本案属终局裁决，建筑公司无起诉权，法院应不予受理或驳回起诉。**
   化解：先核裁决书是否载明裁决类型；解释（一）第18条以裁决书载明为准，未载明而实为终局的，基层法院不予受理、已受理的驳回起诉；同一裁决同时含终局与非终局事项的，依第20条按非终局处理。若确属终局，立即按第49条核算收到裁决书后30日；法院不予受理的，依解释（一）第18条还可自收到不予受理裁定书30日内申请。两起算点不同，先核裁决书送达日与法院裁定日期，不能只盯裁决书送达日；已受理后被驳回起诉的，第49条期间可能已过，须立即向中院核实救济窗口。同步启动和解，不在基层法院空耗。

2. **实体攻击：工伤认定已作出、材料未显示被撤销，建筑公司就是承担工伤保险责任的单位；生效判决确认无劳动关系，恰好证明违法转包，不免责。**
   化解：不在责任主体上硬碰，明确不否认工伤事实与责任主体；把争点收缩到待遇项目范围、基金与单位支付划分、基数核定、已付款抵扣。对刘某的追偿另循途径，不在此案中与其责任混同。

3. **项目攻击：“承担工伤保险责任”即应按条例支付全部待遇项目，包括两项一次性补助金。**
   化解：第37条第1款第(二)项以“劳动、聘用合同期满终止，或者职工本人提出解除”为前提；本案无劳动关系，材料未见张某提出解除，前提不具备。退一步，即使法院认为应支付，一次性工伤医疗补助金亦应由基金支付，标准按所在省规定核定，不能按对方主张的数额直接认定。

4. **参保攻击：未参保则全部待遇由单位支付；基金先行支付后还要向单位追偿。**
   化解：先调取建筑业按项目参保凭证、缴费记录和基金支付情况。已参保的，主张一次性伤残补助金、一次性工伤医疗补助金、医疗费由基金支付，单位仅承担法定单位项目；未参保的，核减超目录医疗费、核减基数、抵扣已付款，并把参保状态作为和解金额的主变量。

5. **执行攻击：裁决生效后，或对方就工伤医疗费等申请先予执行后，张某可申请执行，影响公司账户与经营。**
   化解：评估提供担保、分期和解的可行性；把对刘某的追偿可能性和已付款凭证作为谈判筹码；同时核对裁决书是否已生效、执行依据与金额，避免超额执行。
