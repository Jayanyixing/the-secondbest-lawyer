# C03 策略简报

> **结论**：以冉某主张二倍工资为基准，难以成立，把握度弱；若代理某宾馆，抗辩成立把握较大。
> **最紧迫**：固定续订通知与拒签回复的微信原始载体（证据可能灭失），并核对举证期限、开庭通知（材料未载）。
> **最大缺口**：续订通知的原始记录与《解除劳动合同协议书》全文均未取得。

## 一、争议焦点

1. **核心**：劳动合同期满后未续订书面合同，冉某能否依《劳动合同法》第82条第1款主张二倍工资？〔载：2023-12-10期满后未续签；待核：通知内容、是否附合同文本〕
2. 冉某以“公司要解散，不签合同可以拿二倍工资”为由拒签〔载〕，是否违反诚信原则、构成滥用权利，从而阻却二倍工资？
3. 2024-04-30《解除劳动合同协议书》确认不拖欠此前“工资及其他报酬”〔载〕，是否构成对二倍工资的结清或放弃？
4. 二倍工资的仲裁时效：按月分别起算，还是作为劳动报酬自劳动关系终止起算？
5. 主体与程序：康旅2024-05注销、权利义务由宾馆承继〔载〕，宾馆是否适格被告；农旅作为股东是否担责；仲裁不予受理的理由〔待核〕对法院受理的影响。

## 二、结论预判

材料未载明委托方。以下以冉某（劳动者、原告）主张二倍工资为基准；代理某宾馆的情形见本节末段。

**结论：难以成立，把握度：弱（定性判断，无统计支撑）。**

1. **文义**：第82条第1款以“自用工之日起超过一个月不满一年”为要件。本案用工之日为2018-12-11，2023-12-10期满时已近五年；冉某继续提供劳动不产生新的“用工之日”，不能把期满后的约四个半月直接套入该款。
2. **规范填补**：依《解释（一）》第34条，期满后劳动者继续工作、单位未表示异议的，视为双方同意以原条件继续履行。原书面合同的权利义务由法律拟制延续，难谓“未订立书面劳动合同”。
3. **诚信与可归责性**：二倍工资中的加付一倍具有惩罚性，其适用应受诚信原则与可归责性制约。冉某自认拒签目的是拿二倍工资〔载〕，单位已多次口头及微信通知续订〔载〕；《劳动合同法》第3条要求订立合同遵循诚实信用原则，《民法典》第7条、第132条亦禁止权利滥用；《劳动合同法》第46条第（五）项表明，维持或提高条件续订而劳动者不同意的，单位不承担额外补偿。
4. **结算事实**：解除协议确认不拖欠工资及其他报酬，社保缴至2024-04，经济补偿计算年限截至2024-04-30〔均载〕，显示双方已整体结算。

**若代理某宾馆**：抗辩较强，但不宜乐观。风险一，法院对“期满续订”类推适用第82条（各地口径可能不同，本地库无类案卡片，未检索）；风险二，微信通知若仅“来签合同”、未附合同文本或未明确维持原条件，证明力不足，可能被认定未尽续订义务。一旦败诉，风险期间约为2024年1月中旬至4月（扣除一个月宽限），金额待工资数据测算。

**主要变量**（按影响排序）：

- 续订通知的形式、内容、次数，是否附合同文本、条件是否维持或提高〔待核〕；
- 法院对期满未续签是否适用第82条的口径〔未检索〕；
- 仲裁申请日、不予受理理由及送达日〔待核〕，直接决定时效与程序走向；
- 解除协议全文有无“一次性了结／放弃其他请求”条款〔待核〕；
- 冉某系财务部负责人，是否兼管人事及劳动合同签订〔待核〕；若其本人就是签约责任人，过错在己，抗辩显著增强。

本判断属劳动人事实体问题，按 scope.md 属范围外，仅为初步倾向，不是终局结论（见六）。

## 四、对方最强攻击与化解

**攻击一：严格责任＋类推适用。** 第82条不问用人单位过错，期满未续签即属“未订立书面合同”，二倍工资自期满次月起算。
**化解**：该款文义限于“自用工之日起超过一个月不满一年”，本案用工之日为2018-12-11；《解释（一）》第34条已拟制原条件继续履行；加付一倍具有惩罚性，其适用应受诚信与可归责性制约。
**风险**：若法院采“续订等同新订”口径，文义抗辩被绕过；须做本地类案检索，本地库无同争点卡片。

**攻击二：解除协议不覆盖二倍工资。** “工资及其他报酬”的文义不及于惩罚性二倍工资，协议未列明放弃。
**化解**：协议＋社保＋补偿＋实际履行构成整体结算，依《解释（一）》第35条协议有效；若协议有“无其他争议”条款则抗辩更强。
**风险**：协议全文未取得；若仅有“不拖欠工资”表述，此点较弱，应改以时效、诚信为主，不把宝押在协议上。

**攻击三：时效未过。** 二倍工资属劳动报酬，适用特殊时效，自2024-04-30劳动关系终止起一年。
**化解**：依《调解仲裁法》第27条，普通时效为一年；二倍工资的另一倍是惩罚性赔偿，不是劳动报酬，按其逐月产生分别起算（本文分析意见，本地库无类案卡片支撑）。是否已过时效，取决于申请日与各月起算点的距离；申请日未知，暂不能断言全部未过或全部已过。
**风险**：仲裁申请日未知，有无催告、中断事由未知。

**攻击四：主体不适格。** 仲裁不予受理可能因康旅注销、主体不适格；依《解释（一）》第7条，法院可不予受理或驳回起诉。
**化解**：宾馆依《劳动合同法》第34条、公司法第221条承继康旅权利义务，是适格被告；若不予受理理由为“不属于劳动争议”，依《解释（一）》第6条法院应受理；若为“无管辖权”，依第5条应告知向有管辖权的仲裁机构申请，仍不受理后再起诉。
**风险**：通知书理由与送达日未取得；若确因主体不适格且农旅非适格被告，程序风险高。

**攻击五：拒签正当＋股东责任。** “公司要解散”使拒签具有正当性；微信通知未附合同文本，不构成有效要约；农旅作为股东应否担责。
**化解**：解散之说在材料中无证据支持〔待核〕，且康旅此后仍用工、缴社保至2024-04，注销在2024-05；通知是否附文本需调取原始记录；农旅仅系股东，依公司法第23条第1款需有滥用行为，依《公司法解释（二）》第20条需未经清算或注销时承诺，本案注销有承继安排。
**风险**：若康旅为一人公司，依公司法第23条第3款，财产独立举证责任在股东；工商内档未调取。
