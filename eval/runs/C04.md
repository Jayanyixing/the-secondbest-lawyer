# C04 策略简报

## 一、争议焦点

1. **主体适格**：郑某任生产运营部首席技术官，是否属《劳动合同法》第24条第1款所列人员（高级管理人员／高级技术人员／其他负有保密义务的人员）。材料仅有职务称谓，无任命文件、岗位职责、薪酬与保密协议。
2. **竞争关系（核心）**：某甲与郑某新入职的某生物公司，是否属"生产或者经营同类产品、从事同类业务的有竞争关系"的用人单位。材料给出的唯一连接点是"两公司均系生物医药公司"，属行业与登记经营范围层面的相似，尚非实际经营内容的比对（第24条第2款）。
3. **保密信息归属**：郑某接触的是**关联公司某乙**两款药物的化学成分生产与控制细节。该信息能否认定为某甲可据以主张竞业限制的"本单位"商业秘密，取决于两公司关联关系、委托生产／上市许可持有人安排及保密制度覆盖范围。
4. **责任范围**：710万元违约金是否"过分高于损失"应予酌减；100万元损失有无独立证据、与违约金是否重复；已付196185元补偿应否返还及返还区间；24个月期限届满后"继续履行"有无实益。
5. **程序基础**：仲裁委"以超过法定期限为由终结案件审理"的性质——是逾期未作出裁决（可依《劳动争议调解仲裁法》第43条起诉），还是仲裁时效届满，直接决定起诉能否被受理。

## 二、结论预判（我方主张能否成立、把握度、主要变量）

**立场假设：代理某甲医药公司（仲裁申请人／原告）。** 若实际代理郑某，见本节末"反向"。

- **违约成立（竞争关系）——把握度：弱—中。** 主体适格与保密信息接触两点较强（CTO、两款药物CMC细节、已付补偿），但"竞争关系"目前只建立在"均系生物医药公司"上，恰是指导案例190号明确排除的论证方式。若不能补足产品管线、适应症、客户与渠道、技术路线的实际重合，该要件倾向于不成立。
- **710万元违约金——把握度：弱（全额支持）。** 即使违约成立，710万元与已付196185元补偿、与尚未量化的损失之间明显失衡，法院参照《民法典》第585条第2款酌减的概率高；违约金请求权的依据为第23条第2款。应预设"部分支持"为现实目标，不宜以全额为庭审底线。
- **100万元损失赔偿——把握度：弱。** 《劳动合同法》第90条要求"给用人单位造成损失"，需独立损失证据；且与违约金基于同一违约事实，重复获赔空间有限。
- **返还196185元补偿——把握度：弱—中。** 违约起算日（入职某生物之日）之前的补偿系已履行期间的对价，全额返还缺乏依据；仅该日之后按月折算部分有主张空间。196185元若按24个月折算约8174元／月，若仅为离职至2022年2月的补偿则约4万元／月，两种口径对"违约金是否过高"的判断影响相反，须以支付明细锁定。
- **继续履行——无实益。** 竞业限制期自解除之日起算24个月，〔假设：解除日2021-10-29〕则约于2023-10-28届满；起诉时或可主张，审理、执行阶段期限已过，请求失去履行内容（第40条虽允许在支付违约金后要求继续履行，但以期限未届满为前提）。建议评估撤回或不再坚持。

**主要变量（按影响力排序）**：① 两家公司实际经营内容重合度的证据；② 某乙保密信息能否归属于某甲；③ 违约金约定与补偿标准的对价关系；④ 离职日、入职日与补偿支付明细（决定返还区间与期限）。**建议路径**：一审前集中补证①③，同步做调解测算；不以"同行业"为唯一论点开庭；若①无法补足，收缩为确认违约之诉并另循保密义务路径，不与710万元捆绑。

**反向（代理郑某）**：抗辩重心即下文攻击1、2、3，把握度中—强；核心是要求某甲就"实际竞争"举证，并主张违约金畸高。

## 四、对方最强攻击与化解（≥3 条）

1. **竞争关系不成立（攻击力最强）。** 依据190号，审查竞争关系应结合实际经营内容、服务对象或受众、对应市场，不能仅凭登记经营范围重合；某甲起诉理由只写"均系生物医药公司"，等于自认只有行业层面相似。**化解**：举证两家在具体管线／适应症／剂型上的重叠、同一客户与渠道、某生物招聘岗位与郑某原职责的对应、郑某入职后分管的业务线；申请法院调取某生物的药品注册与临床试验登记、招投标与供应商记录。**评估**：可化解，但完全依赖外部证据，现有材料不足；若调取不能，此点失守。
2. **保密信息属某乙而非某甲。** 竞业限制保护的是"本单位"的商业秘密；郑某接触的是关联公司两款药物的CMC细节，某甲并非当然的权利人，主体与保护利益之间存在断层。**化解**：证明两公司关联关系、某甲为上市许可持有人或委托生产方、集团保密制度与郑某承诺覆盖关联公司信息。**评估**：取决于协议与关联文件原文；若不能证明，只能转保密义务／侵权路径，不能支撑竞业限制请求。
3. **违约金畸高应酌减。** 710万元对比196185元补偿，且某甲未举证实际损失，属"过分高于造成的损失"；竞业限制违约金以补偿为主，惩罚性有限。**化解**：举证研发投入、管线延误、客户流失等实际损失与约定对价，说明补偿标准高于法定下限；同时承认酌减风险并预设调解区间，避免庭审中只守全额而无备选。**评估**：可部分化解，全额几无可能。
4. **100万元损失无据且重复。** 第90条以"造成损失"为要件，某甲未提交损失证据；该请求与违约金基于同一违约事实，构成双重获赔。**化解**：撤回或列为备位；如主张超出违约金的差额损失，须单独举证并说明不重复计算。
5. **返还补偿无依据。** 补偿是郑某已履行竞业义务期间的对价，不因事后违约而全额返还；若协议被认定不构成竞争，返还更无基础。**化解**：仅主张入职某生物之日起对应部分，按月折算并锁定入职日。
6. **程序与合意瑕疵。** 仲裁"超过法定期限"性质不明，若被认定为仲裁时效届满，起诉存在被驳回风险；协议系辞职当日签订，对方可主张系单位单方拟定、无真实协商。**化解**：调取终结文书，依第43条说明系逾期未裁决；若对方以时效抗辩，依第27条核对知道权利受侵害之日与申请日；以补偿实际支付记录、郑某主动告知入职的事实反证其知悉并接受义务。**另需先自查**：若补偿存在连续三个月未付，郑某可依解释（一）第38条主张解除竞业限制约定，直接击穿请求权基础。
