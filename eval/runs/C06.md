# C06 策略简报

## 一、争议焦点

1. **加速到期是否成立**：乙公司注册资本800万元，各股东认缴期限均至2050年6月9日〔待核：以工商内档为准〕；执行终本后，甲公司能否依《变更追加规定》第17条追加未届期股东，还是必须证明公司"已具备破产原因而不申请破产"（《九民纪要》关于加速到期的例外规定，条号待取原文）？
2. **诉讼中300万元是否构成有效实缴**：其中200万元经"陈某→乙公司→陈某华→陈某"两次闭环回流，是否属虚假出资/抽逃出资？公司自行公示与章程备案能否补正？
3. **追加责任范围**：追加裁定作于2022年10月19日；诉讼中补缴能否依第33条调减？100万元已支付给甲公司，应否从陈某328万元中扣除？
4. **甘某72万元部分**：材料未见甘某缴纳凭证，其"期限利益""仅挂名"抗辩能否成立？
5. **程序是否适格**：裁定2022年10月19日作出、2022年12月起诉，是否在送达后15日内（第32条）？

## 二、结论预判（我方主张能否成立、把握度、主要变量）

**结论**：〔假设我方为申请执行人甲公司，请求维持追加〕在加速到期成立的前提下，追加方向成立，但陈某责任范围较可能由328万元调减为228万元，甘某72万元全额维持。
**最紧迫**：核追加裁定送达回证。若起诉逾15日，可先请求驳回起诉，先于实体审理。
**最大缺口**：本地库未收《九民纪要》，"终本＝已具备破产原因"这一加速到期依据只能标"待取原文"；替代路径为新公司法第54条，但须过时间效力关。

- 甘某72万元：**中高**（约75%，以加速到期成立为前提）。无出资凭证；名义股东抗辩不能对抗公司债权人〔N-09〕。
- 陈某200万元闭环：**高**（约85%–90%）认定非真实出资。时间紧接、同额、闭合、重复两次，无交易背景；举证责任已转移至陈某〔N-06〕。
- 陈某100万元：**中高**（约70%）认定为实缴并扣减。款项入公司账户且已支付甲公司；不扣系对我不利、可上诉的争点。
- 全额维持328万元：**低**（约20%–25%）。
- 全案被撤销（加速到期不成立）：**中低**（约20%–30%），取决于法院对《九民纪要》加速到期例外的援引及对"终本"的定性。
- 综合：追加成立（含部分调减）把握度**约70%–75%**；若15日期限抗辩成立，程序上直接胜出。

主要变量：①《九民纪要》加速到期例外能否作为裁判依据、"终本"是否等于"已具备破产原因"；②15日起诉期限；③100万元定性；④闭环转账的证明标准及陈某华交易的对抗解释。

## 四、对方最强攻击与化解（≥3 条）

1. **"认缴期至2050年，股东享有期限利益；旧法无加速到期规定"**——主张加速到期仅限破产、解散等法定情形，本案不符合。化解：终本裁定证明"穷尽执行措施无财产"，材料未见公司申请破产，正落入《九民纪要》加速到期例外；备位援引新公司法第54条＋时间效力规定第4条第（六）项〔N-11、N-13〕。同步申请调取乙公司财产查询反馈及是否进入破产程序。
2. **"300万元已实缴，公示＋章程备案已确认"**——主张出资义务消灭、追加基础丧失。化解：200万元闭环回流，资金未留存公司；依民法典第146条，虚假意思表示无效〔N-10〕；公示与章程备案是形式登记，不能替代银行流水与会计账簿；依解释三第20条，陈某须证明真实、足额、非循环回流，否则承担不利后果〔N-06〕。申请调取实收资本明细账、记账凭证及陈某华基础合同。
3. **"补缴发生在诉讼中，应判决变更责任范围至零"**——依第33条请求全部撤销。化解：仅100万元真实；200万元不实，不能计入；补缴在追加裁定之后，只影响责任范围，不影响裁定作出时的合法性；退一步，100万元可扣，剩余228万元仍应维持〔N-04〕。
4. **"200万元是陈某华与乙公司的独立往来，与陈某出资无关"**——切断闭环与出资的关联。化解：时间紧接、金额一一对应、路径闭合、重复两次，无真实交易背景，已达高度盖然性；申请调取三方完整流水、陈某华身份关系及基础债权凭证，必要时申请审计。
5. **"甘某仅挂名、未参与经营，且认缴期未到"**——主张不承担责任。化解：登记股东对外责任不以实际参与为要件，名义股东抗辩不影响对公司债权人的责任〔N-09〕；材料未见甘某实缴凭证，72万元范围内追加成立；加速到期对其同样适用。
