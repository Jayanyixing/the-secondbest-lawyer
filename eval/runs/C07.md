# C07 策略简报

结论：按「我方＝朱某蓉（案外债权人）」定位，原判应再审撤销并驳回曹某东诉请，把握度「强」；15.91万元执行回转「中强」；朱某蓉实际受偿「中」。

最紧迫：再审已启动，应立即向再审法院提交案外人意见及证据线索，同时向执行法院申请执行回转、恢复执行与财产查控，防止余款被转移。

最大缺口：50万元交付凭证、曹某东与尹某安的讯问笔录均不在手；无案号；材料未载明委托方。

## 一、争议焦点

**立场说明**：材料未载明委托方。本简报以朱某蓉为「我方」展开——她是尹某安的另一债权人、原案案外人，不是原审当事人。若实际委托方为曹某东、尹某安或法院，结论须重做。

1. **借贷是否真实**：曹某东持50万元借条起诉，借条只能证明合意外观，不能证明款项实际交付；大额借贷须审查资金来源、交付方式、款项流向及双方经济状况。
2. **「不持异议」的效力**：尹某安对借款事实不持异议，接近自认。但涉恶意串通、可能损害案外人权益时，自认不能免除法院依职权审查，自认与查明事实不符的不予确认。
3. **再审结果**：原判是否属「基本事实缺乏证据证明」，应否撤销并判决驳回曹某东的请求，而非仅部分改判。
4. **执行回转**：15.91万元系尹某安控制曹某东银行卡实际领取。原判撤销后应否回转、向谁回转、朱某蓉能否就该款受偿。
5. **救济路径顺位**：案外人申请再审、第三人撤销之诉、执行回转＋恢复执行/参与分配、检察监督与刑事控告，何者可行、何者应放弃。
6. **刑民交叉**：公安讯问后认为涉嫌虚假诉讼并移送线索，法院已启动审判监督程序；刑事程序对民事再审的证明作用及是否中止。

## 二、结论预判（我方主张能否成立、把握度、主要变量）

**总体判断**：法律定性上，我方核心主张（原判认定借贷关系错误、应撤销）依据充分，属「强」；但朱某蓉不是原审当事人，不能自己启动再审，也不当然取得对15.91万元的直接给付请求权，实际回款取决于尹某安的现存财产与执行程序进度，属「中」。本判断为定性分析，无统计支撑，不给出胜诉率数字。

**不建议的两条路径**：
- **第三人撤销之诉**（民诉法第59条第3款）：朱某蓉系普通债权人，与原判诉讼标的无独立请求权，通说认为不属于适格第三人；且6个月期间起算点不明，双重风险。
- **案外人申请再审**：须以法院驳回其执行异议裁定为前提；本案执行已完毕，朱某蓉未提执行异议、无裁定可依，程序上无从提起。

**建议路径**：以「法院依职权再审＋案外人意见」为主轴，同步申请执行回转、恢复执行与参与分配；检察监督、刑事控告作为施压与补强。

## 四、对方最强攻击与化解

**攻击1：朱某蓉主体不适格，无权对再审指手画脚。**
化解：不争「再审申请人」资格，争「利害关系人」参与。再审由法院依民诉法第209条依职权启动，朱某蓉以案外人身份提交书面意见、证据线索和《参加再审申请书》，准否由合议庭决定；执行回转是独立程序，朱某蓉可直接向执行法院申请；另可向检察院提交监督申请。三条腿都不依赖当事人资格。

**攻击2：借条真实、尹某安自认、曹某东已完成举证，朱某蓉没有反证。**
化解：自认在本案不生效。其一，解释第92条明确「自认的事实与查明的事实不符的，人民法院不予确认」；其二，解释第96条将「当事人有恶意串通损害他人合法权益可能的」列为法院依职权调查情形；其三，民间借贷规定第18条第6项把「双方对借贷事实没有任何争议」本身列为虚假诉讼的审查标志，第7项更直接涵盖「案外人的其他债权人提出有事实依据的异议」。对方越强调「无争议」，越落入口径。

**攻击3：执行回转只能向账户名义人曹某东，尹某安实际领取是另一层关系；款项已混同，回转不能。**
化解：第244条的对象是「取得财产的人」，不是「账户名义人」。申请调取曹某东账户流水、取款凭证、执行款发放记录，证明尹某安控制银行卡并实际领取，可将曹、尹一并列为回转对象；款项不能返还的，依民法典第157条折价补偿；拒不返还的，依第244条强制执行。

**攻击4：朱某蓉申请参与分配已过时点，且普通债权无优先权。**
化解：不否认时点限制，改走「回转后重新执行」。回转款回到尹某安责任财产后，朱某蓉申请恢复执行或由法院重新立案执行，在该程序中依解释第506条申请参与分配，即在「执行程序开始后、财产执行终结前」提出，符合第507条；若尹某安无其他债权人，直接恢复执行即可，无须参与分配。

**攻击5：公安只是「认为涉嫌」，没有起诉、判决，民事再审不能凭侦查材料定案。**
化解：民事证明标准是高度盖然性，不以刑事定罪为前提。讯问笔录经法院调取、当庭质证后可作证据；结合50万元无交付凭证、双方无争议、执行款回流尹某安三项事实，已形成完整证据链。刑事程序可并行，不构成再审中止的当然理由。
