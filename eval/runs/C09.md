# C09 策略简报

〔自查｜立场假设：代理侯某某（案外人／原告）〕

## 一、争议焦点

1. **合同效力**：2015 年无落款日期的房屋买卖协议，是否因双方通谋虚伪表示而无效；诉讼中双方自认"无真实买卖、实为他人债务担保"，对效力认定有何影响。
2. **价款是否实际支付**：收据载明收到全款，但 140 万元当日分两笔回流侯某某本人及关联方账户，能否认定已付全款。
3. **占有与过户**：查封前是否合法占有；未过户是否可归因于买受人自身原因；2018 年"预查封"是否等同第 28 条所称"查封"。
4. **权益性质**：未登记、让与担保未公示，侯某某有无足以排除强制执行的物权或优先权；确认所有权请求有无实体基础。
5. **程序与制裁**：是否构成虚假诉讼、应否驳回并罚款／拘留／移送；前案驳回过户判决是否产生重复起诉或禁反言效果；起诉是否在异议裁定送达后 15 日内。

## 二、结论预判（我方主张能否成立、把握度、主要变量）

- **不能成立。** 最可能结果：判决驳回"停止执行"请求，确认所有权请求一并驳回，诉讼费由原告负担；若法院认定虚假诉讼，另可能罚款、拘留并移送线索。
- **把握度：弱**（我方胜诉可能性低；定性判断，无统计支撑，不折算百分比）。
- **最紧迫事项**：15 日起诉期限。材料无异议裁定送达日期，**期限状态待核**；若已逾期，实体审理不能进入，应优先核送达回证。
- **主要变量**：
  1. 自认的拘束力——自认不能使无效合同有效，法院仍依职权审查效力，此项空间极小；
  2. 140 万元回流的解释与反证——能否以独立凭证证明系另一法律关系，直接决定"已付全款"能否成立，但与双方自认正面冲突；
  3. 法院对虚假诉讼的处理力度（是否罚款、拘留、移送），决定"案结"还是"案结事不了"；
  4. 预查封的时点与效力、动迁房限售及产证办理进度，决定第 28 条"查封前"与"非自身原因"两项；
  5. 让与担保的主债权是否真实存在——决定能否退守普通债权另案主张。

## 四、对方最强攻击与化解（≥3 条）

1. **攻击：合同因通谋虚伪而无效，第 28 条第一项"合法有效的书面买卖合同"不成立。** 化解：无实质抗辩空间；只能主张无效不影响隐藏的担保关系效力（N-11），但该关系未公示不产生优先受偿，仍排除不了执行。**建议不在此点硬抗，改为主张债权。**
2. **攻击：价款未实际支付——140 万元当日回流本人及关联方，收据系配合出具。** 化解：需以独立凭证解释回流性质（另笔借款、委托付款），但现有材料下无法自洽，且继续主张"已付全款"会加重虚假陈述风险。**建议放弃该事实主张。**
3. **攻击：未合法占有、未过户系自身原因（第 28 条第二、四项），举证责任在案外人（N-07）。** 化解：补交房单、钥匙交接、物业费与水电记录、装修合同、入住登记；若无，放弃该路径，不作无据陈述。
4. **攻击：未登记即无物权（N-03）；让与担保未公示无优先权（N-11）；确权请求无基础（N-08）。** 化解：退守对曹某的主债权或担保责任，另案起诉或申请参与分配；但均不能排除执行，不能作为本案请求。
5. **攻击：构成虚假诉讼，应驳回并罚款、拘留、移送（N-10、N-12）。** 化解：唯一止损路径是如实陈述、撤回不实主张、争取从轻；不得继续以虚假事实推进诉讼，亦不得由律师包装证据。
6. **攻击（程序）：重复起诉／禁反言——前案已驳回过户（N-13）。** 化解：前案诉讼标的为合同履行请求，本案为排除执行的实体权益，请求与标的均不同，不符合三要件；但前案庭审中曹某关于收款的陈述会被作为不利证据使用。
