# 02 民商事诉讼策略与文书

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。刑事主责转 03，财产措施转 07，证据庭审细项转 04，期限转 09。

## 范围

合同、公司、股权、担保、侵权、不当得利、执行异议之诉等民商事诉讼与相关仲裁。劳动争议、破产、知产、建设工程等存在专门程序或专业比对的，先读[范围外](scope.md)划界，再决定能做到哪一步。仲裁、诉讼、执行、破产四条轨道不得混用。

文书类型：起诉状、答辩状、反诉状、上诉状、再审申请书、代理意见、管辖异议、调查取证与鉴定申请、证据目录、调解方案、仲裁申请书与答辩。按需输出，不一次性全给。

## 最小输入

代理谁、对方是谁、请求目标、合同与关键事实日期、履行与违约情况、争议条款、送达与程序通知、已有证据、预期截止。主张股东、关联方、担保人、实际控制人承担责任时，单独分析法律基础与责任形态。

## 办案八步

1. **事实时间线**：分清争议事实、共识、缺口；关联 04 证据编号。对方陈述与初稿描述不写成“法院已查明”。
2. **定请求权基础**：按顺序检索并逐层记录——合同（成立、生效、履行、违约）→ 缔约过失 → 单方允诺与悬赏 → 无因管理 → 物权与占有返还 → 不当得利 → 侵权 → 其他法定之债。**请求权竞合**时列明各自的构成要件、举证难度、时效、赔偿范围与管辖，选一条为主、其余备位，不用“都写上”代替选择。
3. **要件—证据—抗辩对齐**：每个要件写“待证事实／现有证据／证明责任在谁／缺口”；抗辩分三层（权利未发生、权利已消灭、权利受阻），再抗辩单列。禁止只写结论式“构成违约”。
4. **程序审查**：主管与管辖（级别 → 地域 → 专属 → 协议管辖 → 移送与管辖异议）、前置程序、仲裁条款效力线索、主体适格与主体状态、诉讼时效与除斥期间。北京律师受托不等于北京法院有管辖权；网络、金融、知产等专门管辖具体核。
5. **依据核验**：交 01 核关键法条与正反类案，说明一般规则、例外、地域差异与事实差异。不按法官身份或少量案件编造倾向判断。
6. **方案比较**：主方案与备选方案，比较支持条件、最大障碍、补证要求、周期、费用、执行性。胜诉可能性用有依据的定性分析（强／中／弱／无法判断）；用户要数字时说明无统计支撑则不给数字。
7. **金额另建明细**：本金、已付抵扣、损失构成、利息或违约金依据、起止日、利率来源（如全国银行间同业拆借中心公布的贷款市场报价利率，写清期限档次与起算日）、分段、日数口径、暂计日、公式。检查重复计付、约定与法定并用、大小写一致。诉讼费、保全费、鉴定费按现行规则核，不凭记忆报价。
8. **成稿与联动**：核对受理机构当前格式要求，要素式文书有模板时按模板。正文只写与请求相关且有根据的事实与论证，不把内部胜率分析写进提交稿。定稿前与 04／07／09 对齐证据、措施与期限，再交 10。

## 请求写法

- 明确诉的类型（给付／确认／形成），请求可执行、可计算、无歧义；
- 利息、违约金写到“计算至实际清偿之日止”并给计算口径；
- 诉讼费、保全费、律师费（有依据时）的负担请求单列；
- 备位请求、反诉、抵销逐项核对适用条件，避免重复赔偿或事实自相矛盾；
- 涉及继续履行、解除、恢复原状的，写清履行内容与时点。

## 大材料处理

材料超过能一次读完的量时，先出**材料索引表**（材料号｜文件名｜起止页｜类型｜争点标签｜可读性），再按争点局部读取。索引表作为引用定位的唯一依据，页码引用只能落在索引内；索引外的内容不引用。

## 标准交付

- **策略简报**（≤1 页）：目标、争点、建议路径、对方最强抗辩、补证、决策点；
- **争点矩阵**：请求／抗辩 → 构成要件 → 证据与缺口 → 规范与案例 → 程序动作；
- **文书正文**：标题、当事人、请求、事实与理由、受理机构、落款、附件；
- **核验附录**：事实来源、法律版本、类案底稿、金额明细、待补事项、重要期限。

## 自检

诉讼身份与法律关系准确；无情绪化与无据指控；缺项用 `【待补】`；主文、证据目录、金额表、附件相互一致；核心缺口未闭合时标为“待补材料稿”，不称定稿。
