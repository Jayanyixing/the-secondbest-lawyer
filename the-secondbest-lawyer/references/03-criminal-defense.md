# 03 刑事辩护与刑事文书

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。程序期限与节点交 09 核算，证据细项交 04。

## 先定身份

是**犯罪嫌疑人／被告人辩护**、**被害人代理**、**刑事控告**还是**企业涉刑风险分析**？四种立场分别处理，同一工作区不向利益冲突方输出策略。

再确认：涉嫌罪名、办案机关、程序阶段、强制措施及实际执行时间、羁押场所、已收法律文书、可用案卷范围、委托与授权。紧急事项最先列。

## 分阶段

1. **时间线**：从拘留、逮捕、取保、传唤等文书与真实执行记录建节点表，交 09 核期限。侦查、审查起诉、一审、二审、死刑复核分别核规则与延长、重新计算、中止情形，不把“37 天”等经验值套到所有案件。
2. **侦查阶段**：合法会见提纲、强制措施变更申请、羁押必要性材料、初步法律意见。按当前阶段与身份核验会见、了解案情、取证、阅卷的权限，不假定已有完整阅卷权。
3. **审查起诉与审判**：实际取得材料后才做阅卷目录、卷页索引、程序问题清单、补充材料清单。只读部分案卷就标明范围；未见某份材料不等于办案机关没有该证据。
4. **要件拆解**：按罪名拆主体与身份、主观要素、行为、对象、数额与后果、因果关系、既未遂、共同犯罪地位与作用。逐项检验控方证据链与合理疑点。
5. **分层辩护**：无罪（事实不存在／不构成要件／违法阻却／责任阻却／程序根本违法）、罪轻、罪名变更、参与程度、量刑，分别陈述并标事实前提。互斥的假设不写成已承认事实。
6. **认罪认罚与程序选择**：整理证据基础、权利告知、法律后果、争议点，交律师与当事人真实沟通。不替当事人作意思表示，不以从宽为条件诱导不真实供述。
7. **法律时点**：核行为时点的刑法条文、修正案、司法解释与从旧兼从轻规则；量刑核对现行全国规范、北京适用文件、数额标准与情节。给有来源的区间，区间不等于判决结果。
8. **涉案财物与交叉问题**：追赃退赔、涉案财物处置、民刑交叉、企业合规整改分别列路径。民事清偿不当然决定罪与非罪；不以刑事控告威胁实现民事利益。

## 辩护要点检查表（逐项写“成立／不成立／待查＋依据”）

| 层次 | 检查点 |
|---|---|
| 管辖与程序 | 立案与管辖、强制措施合法性、讯问合法性（时间、地点、人数、同步录音录像）、告知与律师帮助权、羁押必要性、期限是否超期 |
| 主体与身份 | 年龄、责任能力、特殊主体身份、单位犯罪与直接责任人 |
| 主观 | 故意／过失、明知内容与程度、目的、动机、认识错误 |
| 客观 | 行为方式、对象、数额、后果、因果关系、既未遂、中止 |
| 违法性 | 正当防卫、紧急避险、法令行为、被害人承诺（限可处分法益） |
| 有责性 | 责任年龄、责任能力、期待可能性、违法性认识 |
| 共同犯罪 | 地位作用、犯意联络、超出共同故意的部分、主从犯 |
| 证据 | 口供与客观证据印证、同步录音录像、电子数据提取、鉴定资质与过程、非法证据排除条件 |
| 罪数与量刑 | 一罪与数罪、牵连与竞合、自首立功坦白、退赔谅解、缓刑与实刑情节 |

“程序瑕疵”分三类：可补正、影响证明力、触及非法证据排除。三类不混称，排除申请须核法定条件、线索材料与提出时点。

## 标准交付

- **紧迫事项卡**：阶段、事实来源、已核执行时间、待核节点、责任律师、下一步；
- **要件与案卷矩阵**：要件／控方材料卷页／有利材料／矛盾与缺口／待核依据／建议动作；
- **分阶段工作计划**：会见、阅卷、取证、申请、意见的目标与合法路径；
- **指定文书**：取保候审或变更强制措施申请、羁押必要性意见、辩护意见、不起诉意见、排除非法证据申请、辩护词、上诉状、被害人代理意见（按需选，不全给）；
- **附录**：法律与案例底稿、程序期限、材料限制、待律师决定事项。

## 边界

不向家属传递依法不得传递的案卷或信息；不引导改变口供、串供、逃匿、删除数据或接触受保护证人；不虚构会见笔录与签名。模拟发问与可能回答必须标“模拟”，不生成可冒充真实供述的文本。文书措辞区分“涉嫌”“指控”“已裁判”。涉未成年人、性侵及其他不公开信息单独隔离，不写入可外传部分。
