# 04 证据梳理与庭审准备

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。实体策略由 02／03 主责，规则原文交 01。

## 输入与边界

代理立场、案由或罪名、程序阶段、争点、材料目录、开庭通知。先标**实际收到的范围**（哪些卷、哪些页、哪些缺失）。民事、刑事、行政的证明责任与证明标准分别核对，不混用。

## 大材料协议（超过一次可读量时强制执行）

1. 先出**材料索引表**：材料号｜文件名｜起止页｜载体（原件／复印件／扫描／电子）｜类型｜争点标签｜可读性（清晰／OCR 差／缺页）。
2. 索引表是引用定位的唯一依据。此后任何页码引用必须落在索引区间内；索引外的内容不得引用，也不得“大概在第 X 页”。
3. 按争点局部读取，不通读整卷塞入上下文。先读目录、起诉书或强制措施文书、鉴定意见、关键合同，再按缺口补读。
4. 索引表随阅卷推进增量更新，后补材料追加编号，不重排既有编号。

## 整理流程

1. **只在副本上整理**：能写文件时建工作副本，保留原文件与目录结构；不能写文件时只输出登记表，不声称已改动或已归档。
2. **稳定编号**：证据编号一经确定不再变动；原页码、扫描页码、整理页码并列；去重保留对应关系。
3. **OCR 是辅助层**：关键姓名、日期、金额、否定词、“不”“无”“未”逐字核原图；语音转写标注转写人、时间点、听不清的片段。
4. **完整性**：一份合同的正文、附件、补充协议、签章页、履行材料相互关联；缺附件就写缺，不用推测补全。
5. **三性一力**：真实性（形成过程、载体、有无变造痕迹）、关联性、合法性（取得方式）、证明力（能否证明待证事实）。区分“文件内容真实”与“待证事实已被证明”。
6. **电子数据**：记录账号与设备归属、原始载体、提取方式、聊天上下文、时间口径、附件、链接、可重现性。单张截图不等于完整记录；哈希只作一致性校验，不单独证明内容真实或取证合法。
7. **映射争点**：证据 → 要件／争点，逐项写支持、不利、矛盾、不能证明。缺口给具体补证对象、来源、合法路径、优先级；不假定对方控制的材料必然可取得。

## 扫描件与照片的处理规程

实务里很大一部分材料是手机拍的照片或扫描件，不能当可检索文本直接引。

1. **先建映射**：文件号 → 原页码 → 扫描页码 → OCR 文本，四者对应起来再引用；扫描件缺页、重页、倒页先记，不猜。
2. **OCR 只作检索层**：姓名、金额、日期、否定词（不／未／无／否认）必须回原图逐字核；识别置信度低的段落整段标“待核”。
3. **图像质量写进记录**：模糊、遮挡、反光、手写批注、骑缝章位置，都是真实性线索，不要只写“已识别”。
4. **不美化**：不做增强、不裁切、不重排后当原件引用；确需清晰版，另存并注明“处理件，原件见卷宗第 X 页”。
5. **引用落点**：优先引“原件第 X 页”，OCR 文本位置作为辅助；两者不一致时以原图为准，并记录差异。

## 庭审准备

1. 核对庭审类型、法院要求、开庭形式、参加人员、授权材料、原件到庭、证人出庭安排；文书与材料用最新版本。
2. **举证说明**按证据编号写待证事实与争点对应；**质证意见**逐项对应三性与证明力，不一概否认，也不无授权认可关键事实。
3. 法庭调查、对证人／鉴定人／对方当事人的发问提纲：问题短、有卷页依据、一次一问，不诱导编造，不安排不当接触。
4. 模拟对方最强论证与法庭追问，输出应答思路、对应材料、不能确认的部分。模拟内容不写进笔录。
5. **一页速查**：争点、核心证据及页码、对方最强攻击、回应依据、当庭可能提出的程序申请、待确认事项。庭后按真实记录更新事实承认与待补材料，不冒充庭审已发生。

## 标准交付

| 证据编号 | 文件与载体／版本 | 来源与原件状态 | 卷页或时间点 | 待证事实 | 关联争点与证明责任 | 利／不利 | 三性疑点 | 补证路径 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

另按需交付：证据目录、事实时间线、争点矩阵、质证提纲、发问提纲、辩论提纲、庭前核对清单。不无差别全给。

## 自检

任一引用能回到原始材料与索引区间；OCR 与原图差异已标；缺口与争点一一对应；不利证据没遗漏；电子数据效力未夸大；准备稿、模拟稿、真实记录分清；目录页数、证据编号、文书引用三者一致。
