# 06 企业信息与法律尽职调查

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。财产与执行线索转 07，争议策略转 02。

## 输入与范围

交易目的、客户立场、目标企业全称与统一社会信用代码、调查基准日、历史期间、实体与关联方范围、交付对象、重要性标准、可用资料。只有企业名称时，先排除同名、历史名称、注销、迁移、改制。自然人信息只处理必要且合法的部分。

本模块做**企业基础核验与法律尽调**。财务审计、税务、资产评估、技术检测、工程造价不冒充已覆盖；需要专业判断的事项列协同需求与对法律结论的影响。

## 流程

1. **范围表与资料清单**：设立与沿革、股权与出资、治理与授权、资产与负债担保、重大合同、劳动人事、许可资质、知识产权、数据与行业监管、争议与执行、关联交易。逐项标“已完成／部分／未做”，不机械宣称全覆盖。
2. **主体核验**：国家企业信用信息公示系统（`www.gsxt.gov.cn`）查公开主体信息，区分登记事项、企业年报自报、即时公示、机关公示；每条核对统一社会信用代码与历史状态。商业库只用于扩展线索。
3. **争议与执行**：中国裁判文书网、中国执行信息公开网（`zxgk.court.gov.cn`）、法院公告、监管处罚与许可披露，按事项补查。非公开仲裁与未公开诉讼无法靠公共检索穷尽，报告必须写这一限制。
4. **交叉核对**：公开信息与营业执照、章程、股东名册、决议、出资证明、合同、权属材料、台账、访谈记录对照。企业声明与访谈未经外部印证时单独标，不伪称已现场核查或已函证。
5. **股权与控制**：分列法律股权、表决安排、实际控制线索。同一电话、地址、人员、投资关系只作关联线索，不直接认定控制、人格混同或共同责任。认缴不等于实缴，注册资本不等于净资产。
6. **风险链条**：事实 → 材料定位 → 规范 → 风险机制 → 影响 → 整改。风险要挂到交易动作上：交易前提、交割条件、先决补正、陈述保证、赔偿、价款调整、交割后管理，由有权主体决定。
7. **口径**：区分“本次未检索到”“企业称不存在”“资料支持在限定范围内不存在”“无法判断”。基准日后新增事实进更新记录，不改写历史口径。

## 否定性结论的写法

不写“无任何风险”“无债务”“无诉讼”。改写为：`截至【基准日】，依据【资料清单】及在【检索范围与平台】内的检索，未发现【具体事项】；【非公开渠道／未提供的资料】不在本次范围内，不能据此推定不存在。` 否定性结论必须同时具备：基准日、资料清单、检索范围、限制声明。

## 脱敏

对外输出与商业库检索时：企业名称可保留（公开主体），自然人姓名留姓、身份证号前 6 后 4、账号后 4、地址到区、手机号前 3 后 4；交易金额按需做区间化处理；涉密合同条款摘取必要片段，不整篇外传。

## 标准交付

- 范围与限制、基准日、检索日期、资料目录与完成度；
- 企业身份与沿革、股权控制结构（文字或可核验图示）；
- **核验底稿**：事项 → 事实 → 资料名称与页码／官方链接 → 时间 → 来源状态 → 冲突与待查；
- 重大风险摘要、分模块分析、补充问题、整改清单；
- 风险表：

| 事项 | 已确认材料所载事实 | 待核实或矛盾 | 法律依据与适用 | 等级与触发条件 | 对本次交易的影响 | 整改或保护条款 | 责任方与时间 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## 自检

范围表述准确（“截至基准日，依据所列材料及在所列范围内完成的检索……”）；法律意见的事实基础与保留事项可查；资料缺失影响核心结论时标为重大限制；公开查册不等于登记档案全量调取，也不等于银行、税务、不动产资料已查清。
