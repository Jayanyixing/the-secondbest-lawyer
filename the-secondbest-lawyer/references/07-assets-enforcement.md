# 07 财产线索、保全与执行

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。刑事涉案财物先与 03 核程序，期限与回执台账交 09。

## 输入

债权或请求基础、当前阶段、义务主体全称与统一社会信用代码、目标金额、紧迫风险、已有判决或执行材料、已知财产与已采取的措施、线索来源与授权范围。关联企业资产不当然是被执行人的资产；历史持有不等于现在持有。

## 三类材料分开

| 类别 | 能做 | 不能做 |
|---|---|---|
| 公开信息 | 公示系统、执行信息公开网、法院公告、依法公开的拍卖与监管披露 | 把公开线索当已查明财产 |
| 委托人合法持有 | 合同、付款凭证、发票、往来记录、权属文件、往来函件 | 扩展到与本案无关的第三方信息 |
| 需依法调取 | 引导申请法院调查、调查令、主管机关查询、律师自行调查的法定范围 | 声称可以公开查到银行流水、个人不动产车辆、证券账户、通信信息 |

线索台账每条保留：具体出处、时间、识别字段、核验等级、不足。不扩展传播无关个人信息。不购买泄露数据，不使用冒名账号、社工库、非法跟踪或内部关系查控；用户提出时改为合法申请与线索整理。

## 保全与执行分析

1. **四态区分**：线索／已核实权属／已核实负担（抵押、查封、轮候）／已采取措施（有回执）。四者不混用，“已冻结”只写有法院回执的。
2. **阶段化**：诉前保全、诉中保全、执行、恢复执行、执行救济，分别核请求基础、紧迫性、范围与比例、担保、错误保全风险、与主案衔接。不因用户要求冻结就认定符合条件。
3. **价值口径**：账面、评估、市场线索、预估可回收值分开。先扣优先权、既有措施、处置成本与税费，再给有前提的回收分析；不以起拍价当回款。
4. **扩张主体的路径**：未缴出资、抽逃出资、变更追加被执行人、撤销权、代位权、执行异议之诉、破产衔接，逐项核成立条件、程序与时点。不凭关联关系自动扩大义务主体，也不为规避执行出方案。
5. **期限**：查封冻结期限、续封、申请执行期间、异议与复议期间交 09 建台账，标起算凭据。没有法院材料不猜剩余期限。

## 保全担保与成本

保全不是免费的，谈方案时必须把钱说清楚，否则客户以为“申请了就能冻”。

1. **担保方式三选一**：现金（按法院要求比例存入或冻结）、保函（银行或担保公司出具）、责任保险（保险公司保全责任险）。各院接受的范围与比例不同，**先问承办法院立案或保全窗口的实际要求**，不按记忆给比例。
2. **成本明细**：担保费或保函费率、保险费、保全费（按标的额分段计收，具体标准现核）、可能的反担保物占用、以及错误保全的赔偿风险。做一张“保成本 / 预期可回收”的对比，客户才做得了决定。
3. **错误保全风险**：申请金额明显超过权利基础、查封无关财产、超期未起诉或未续封，都可能承担赔偿责任。方案里写明这一条，并由客户书面确认知悉。
4. **担保不足时的替代**：缩小保全范围、只冻特定账户、先做证据保全、以调解换取履行担保；不建议用“先冻了再说”推进。
5. **保全后管理**：查封冻结有期限，续封要提前办；和解或撤诉后及时申请解除，避免给对方造成损失反过来索赔。

### 行动方案

按紧迫性与可行性排序：立即保全评估 → 公开补查 → 依法申请调查 → 执行申请与救济 → 长期关注。每项写需要的证据、规则、负责人、衔接节点。

### 文书草稿

保全申请、财产线索表、调查或调查令申请、执行申请、执行异议与复议文书，附材料清单、待补信息、金额明细。按当前程序选，不全给。

## 自检

每条线索有来源与时间；线索未冒充查明资产；被执行、失信、限制消费、无财产可供执行四种状态准确区分；关联方资产未擅自归入；措施状态以真实回执为据；没有来源不明的私人信息。
