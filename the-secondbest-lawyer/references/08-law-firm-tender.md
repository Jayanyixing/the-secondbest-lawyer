# 08 律所投标与法律服务方案

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。关键节点与截止交 09 建表。

## 输入

招标或采购文件全部版本与澄清更正、采购方式、项目与包号、截止与递交方式、律所主体与资质、拟投入人员、**获准使用的真实业绩**、价格权限、内部审核流程。区分政府采购、企业采购、律所入库遴选，不套同一套采购法规与格式。

## 流程

1. **版本与时间表**：采购文件版本表（编号、日期、来源）＋关键时间表（答疑、澄清、保证金、递交、开标、有效期）。更正与答疑逐条落到正文，旧版作废内容标明。中国政府采购网（`www.ccgp.gov.cn`）与采购人指定平台查公告；平台受限时说明，不用第三方转载代替最新正式文件。
2. **三类要求分开**：资格性要求（不满足即无效）／实质性响应要求／评分项，逐条摘录并留页码或章节号。“必须满足”与“争取得分”不混在一张清单。
3. **响应矩阵**：要求 → 应答 → 证明文件 → 标书位置 → 缺口 → 负责人。真实材料不足就写待补及对资格或分值的影响。
4. **材料核验**：有效期、使用授权、主体与人员对应关系、证书真伪线索。涉客户秘密、案件内容、个人信息的业绩材料按获准范围脱敏；不得复制签章或伪造证明。**编造业绩属于硬性禁止项**，发现缺口只写缺口。
5. **方案设计**：需求与法律问题 → 服务范围 → 项目组织与人员分工 → 工作步骤与里程碑 → 交付物 → 响应机制与时限 → 保密与利益冲突管理 → 质量控制 → 应急与退出。承诺须可实现、由有权人员确认；不承诺裁判结果，不暗示与办案机关的特殊关系。
6. **报价**：按采购文件核对税费、币种、计价单位、人员或工时、分项合计、总价、大小写、限价、报价有效期。缺价格授权或税务口径时给带条件的测算，不代定商业报价。商务偏离与技术偏离如实披露。
7. **程序性细节**：电子投标的 CA 证书与电子签章、文件格式与容量、命名规则、上传时点；纸质投标的密封、份数、正副本、签章位置；保证金形式与退还条件；联合体协议与分包限制；暗标或匿名评审的可识别信息处理（按规则办，不自作主张全篇脱敏）。
8. **复核**：引用、页码、交叉引用、附件完整性；实际生成 Word／PDF 时检查最终呈现；只交 Markdown 时标明尚需排版与签章，不称“可直接上传的电子标书”。

## 标准交付

- 项目摘要、投标可行性、硬性缺口、截止事项；
- 资格性与实质性要求检查表；
- 评分响应矩阵：

| 采购要求与定位 | 类型／分值 | 具体响应 | 证明材料与版本 | 章节／页码 | 满足情况与缺口 | 责任人 |
|---|---|---|---|---|---|---|
| | | | | | | |

- 标书内容或指定章节稿，按采购文件顺序组织；
- 报价核对表、商务／技术偏离表、证明材料与签章清单；
- 递交前检查表，分“已核对／待补／待负责人决定”。

## 自检

每个实质性要求都有对应；评分写实且有证明；报价全稿一致；主体、人员、期限无错配；更正已合并；未造章造证、未披露未授权客户资料；资格硬缺口不靠“完全响应”掩盖；未取得负责人授权不发送、不承诺报价。
