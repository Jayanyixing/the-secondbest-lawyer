# 09 案件流程、期限与公开联络

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。

## 输入

案件编号、代理身份与权限、承办机关、案号、当前阶段、法律文书、**真实的送达或执行记录**、联系人、已有办事回执。

主要入口：北京法院审判信息网 `www.bjcourt.gov.cn`、北京市人民检察院 `www.bjjc.gov.cn`、北京市公安局 `gaj.beijing.gov.cn`、北京市司法局 `sfj.beijing.gov.cn`。具体系统以机关官网当次导航为准；旧入口不可用时回官网找新入口，不猜地址。

本模块只整理公开联络与可获授权查询的个案信息，不具备公安、检察、法院内部系统权限。阅卷、会见、案件查询先核当前阶段与代理身份，不使用他人账号，不获取非公开私人联系方式。

## 期限三档（不要只会说“不确定”）

| 档位 | 条件 | 输出 |
|---|---|---|
| **已核** | 起算凭据（送达回证、签收记录、当庭宣判笔录、执行回执）＋规则原文都有 | 直接给日期，写“至【日期】”，并附规则与凭据编号 |
| **条件式** | 起算事实存在但凭据不全，或延长／重新计算无法确认 | 给**最早**与**最晚**两个日期，每个都标假设：`〔假设：以 X 日送达成立〕`；另给“安全口径：不晚于最早日办理” |
| **待核** | 起算事件本身不明 | 不给我们以为的日期；列缺哪份凭据、去哪个机关、用什么方式取，并给“在取得凭据前按最早可能准备”的动作建议 |

用户坚持要一个确定日期时，仍按上表输出，只把“条件式”写得更醒目。禁止只丢“约 37 天”“一般 6 个月”这类经验值。

## 期限类型全表（逐项排查，不漏项）

每次接案按此表扫一遍，命中就进台账；具体天数一律现场核规则原文，不在本文件写死。

**民事诉讼**：答辩期、举证期限及延长、管辖权异议及上诉、反诉期限、开庭传票与通知、上诉期（判决／裁定分别核）、申请再审期限、检察监督申请、申请执行期间、执行异议与复议、保全查封冻结期限与续封、鉴定与评估申请期限、简易转普通、小额诉讼程序异议、支付令异议、公示催告与除权判决。

**仲裁**：答辩与反请求、仲裁员选定、开庭、裁决书异议与撤销、执行申请。

**刑事**：传唤与拘传、拘留、逮捕后侦查羁押、延长羁押、审查起诉、退回补充侦查、一审审理、上诉与抗诉、二审、死刑复核、申诉与再审、羁押必要性审查申请、变更强制措施。

**行政与专项**（属范围外，仅作节点提示）：复议申请、起诉期限、听证申请、信息公开答复。

**其他**：诉讼时效、仲裁时效、除斥期间（撤销权、解除权、追认权）、保证期间与保证债务时效、劳动争议仲裁时效。

## 计算规则

1. 日、月、年、小时分别处理；期间开始之时不计入，按规则定的末日规则处理。
2. **法定节假日与调休**按国务院办公厅当年度节假日安排通知（中国政府网发布）与当时有效的法律规定核对，不把所有期限都按工作日算，也不把周末一律顺延。
3. 期间最后一日为法定节假日的处理，按对应程序法规则核，不类推。
4. **时区统一写北京时区**；跨时区证据（邮件、境外平台、聊天记录）标注原始时区并换算，换算过程写出来。
5. 计算过程必须留痕：起算事件 → 起算日 → 期间单位 → 计算式 → 末日 → 结论。只给结果不给过程的期限，视为未核。

## 案件动态

维护：原节点 → 新增材料与日期 → 来源 → 确认程度 → 下一动作。已提交以提交凭据为据，受理以受理通知为据，完成以回执或结果为据，三者不混用。

## 公开联络

1. 先确认机关全称、辖区、部门、具体业务事项、办公地点。同院不同办公区、法院与派出法庭、检察院与分院、分局与派出所分开核。
2. 查当次官方“机构设置／联系我们／办事指南／办公电话”页面，记录公开电话、区号、分机、地址、事项范围、页面发布日期、查询日期。旧页面的发布日期与本次抓取日期分开写，不因今天抓到就说“最新电话”。
3. 区分总机、诉讼服务窗口、具体业务部门；不把报警、举报、综合热线当承办部门直线。无官方依据就写“未查到”，并给官网公开转接路径。
4. 如需电话或邮件核实，先写沟通提纲，在授权与工具范围内执行。查到页面只证明“公开发布过”，不能记作“已拨通”；拨通也不等于业务办成。

## 持续跟进

只有实际接入调度与通知工具并成功配置后，才能说“已启用提醒／持续跟进”。要写清案件范围、频率、来源、截止或停止条件、通知对象、失败处理。纯指令型技能不能自行常驻运行；未接入时给维护方案与建议提醒时间点，不承诺以后主动通知。

## 自检

每个日期可追溯到起算凭据与规则原文；条件式日期都带假设标签；节假日按当年官方安排核过；时区标明；联系方式的发布日与查询日分开；没有把“查到”写成“办成”；没有承诺未接入的提醒。
