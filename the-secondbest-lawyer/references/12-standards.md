# 12 标准检索与适用（国标／行标／团标）

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。本模块管“技术规范怎么查、怎么用”，不管工程造价鉴定与专业检测本身（见 [范围外](scope.md)）。

## 先定性质：标准不是法源

国标、行标、团标严格说是**技术规范**，但在四种情形下产生规范效力，必须分开说，不能一句“不符合国家标准”了事：

| 情形 | 效力来源 | 用法 |
|---|---|---|
| 强制性国家标准（GB） | 法定强制，不符合即不得生产、销售、进口或提供 | 直接作为产品不合格、不合法的事实依据 |
| 被法律、法规、规章或司法解释引用 | 经上位规范取得约束力 | 条文与标准**两个都引**，不能只引标准 |
| 合同、订单、技术附件、招标文件约定 | 约定效力，与推荐性／团标身份无关 | 回到合同条款，标准是履行标准 |
| 单纯推荐性（GB/T、行标、团标） | 自愿采用 | 只能证明行业惯例、技术合理性或过错，不能单独定“违法” |

一句话记住：**标准能证明技术合格与否，不能证明法律上合法与否；符合标准也不当然免责。**

## 代号速查

| 类型 | 代号 | 说明 |
|---|---|---|
| 国家标准 | GB | 强制性 |
| | GB/T | 推荐性 |
| | GB/Z | 指导性技术文件 |
| 行业标准 | 例：JGJ（建工）、CJJ（城建）、JTG／JTS（公路／水运）、HJ（生态环境）、WS（卫生）、JR/T（金融，推荐性）、JB/T（机械）、YD/T（通信）、TB（铁路）、SY（石油天然气）、DL（电力）、HG（化工）、QB（轻工）、FZ（纺织）、NY（农业）、SL（水利） | 由国务院有关行政主管部门制定、报国家标准委备案；**具体代号以平台显示为准**，`/T` 后缀表示推荐性 |
| 地方标准 | DB + 行政区划代码 | 北京为 DB11 |
| 团体标准 | T/团体代号 顺序号—年份，如 T/CESA、T/CCFA | 学会、协会、商会、联合会、产业技术联盟等制定 |

## 检索五步（按顺序，不跳步）

1. **核效力**：全国标准信息公共服务平台 `std.samr.gov.cn` —— 国标、行标、地标、团标统一查。用它核**现行／即将实施／废止／被代替**最稳。
2. **取全文**：综合平台查不到时去归口部委平台：
   - 住建／工程：住房和城乡建设部 → 工程建设标准化信息网（JGJ、CJJ 等，住建部通常免费公开工程建设标准全文）
   - 生态环境：生态环境部 → 生态环境标准检索平台（HJ 系列，官方免费 PDF）
   - 卫生健康：国家卫健委 → 卫生健康标准网（WS 系列，官方免费全文）
   - 金融：中国人民银行、证监会 → 金融标准全文公开系统（JR/T 系列）
   - 工信／通信／机械／化工：工业和信息化部 → 工信部标准网，或行业收录库
   - 国家标准全文公开系统 `openstd.samr.gov.cn`：免费公开**强制性国标与推荐性国标**，部分行标只到题录（受出版机构版权限制）
3. **查团标**：全国团体标准信息平台 `www.ttbz.org.cn` —— 按标准号、名称关键词、社会团体名称检索。这是团体标准**自我声明公开**的国家级平台，状态会标注；部分团体公开全文，部分只有题录与起草单位。
4. **查到全文才引用**：团标只查到题录时，去发布团体官网或官方公众号的“标准工作／通知公告”找发布原文与附件。
5. **查司法适用**：用裁判文书与商业库看法院实际怎么用这条标准（是否作为质量依据、是否被认定落后于上位法）。商业库（威科先行、北大法宝、法信、Alpha、聚法等）主要解决“法律效力＋案例适用”，标准正文仍回官方渠道。

检索留痕：平台、检索式、检索日期、命中条目、实际打开的范围、失败原因。标准平台也常限流或维护，受限就写明，换入口再试一次。

## 效力四态与版本

每一条标准都要记四项，缺一项就别引用：

`状态`（现行／即将实施／废止／被代替，被代替的写明代替它的标准号）＋`标准号含年份`（年份是**版本**，同名不同年可能实质不同）＋`实施日期`＋`查询日期`。

行为时点适用当时有效的版本，不用最新版套旧行为——与法条时点规则一致。合同约定了旧版而新版已实施时，先看约定，再核是否存在强制适用要求，把理由写出来。

团体标准设有复审周期，是否继续有效以平台标注为准，不自行推定。

## 引用的正确写法

> 《XX技术规范》（GB/T XXXXX—20XX）第 X.X 条〔S-01｜官方平台｜状态：现行｜查询 2026-11-08〕

- 标准号＋年份＋名称＋条款号，缺一不可；
- 标准全文有版权，**不整篇复制**，只摘必要条款并标条款号；
- 摘录、定位、回读规则与法条一致（见 [citation.md](citation.md)），标准另用 `S-` 前缀编号。

## 在业务中的用法

- **诉讼**：作为质量不符、行业惯例、过错或减损义务的依据；质证重点是该标准的版本是否适用、是否强制性、是否已被代替、适用范围是否覆盖本案产品。
- **合同**：区分“约定标准”与“法定标准”，检验条款写清以哪一版、哪一条验收；招标文件引用标准时核对是否与现行版本一致。
- **尽调／合规**：查资质与标准符合性、抽检与处罚记录；强制性标准是合规底线，不能靠“行业普遍这样”抗辩。
- **不要做**：拿推荐性标准当强制规范指控对方违法；用已废止标准论证；用标准替代法律依据；把“符合标准”写成“无任何责任”。

## 自检

标准性质（强制／推荐／团标）说清了吗；状态与版本年份核过吗；强制性与合同约定分开写了吗；条文与标准双引了吗；全文来源可定位吗；没有整篇复制吗；查询日期写了吗。
