# 12 标准检索与适用（国标／行标／团标／企标）

通用规则见主 `SKILL.md`；引用按 [citation.md](citation.md)。本模块管“技术规范怎么查、怎么用”，不管工程造价鉴定与专业检测本身（见 [范围外](scope.md)）。

## 先定性质：标准不是法源

国标、行标、团标严格说是**技术规范**，不在立法法的位阶序列中。它在四种情形下产生规范效力，必须分开说，不能一句“不符合国家标准”了事：

| 情形 | 效力来源 | 救济路径 | 用法 |
|---|---|---|---|
| 强制性国家标准（GB） | 法定强制，不符合即不得生产、销售、进口或提供 | 违法／不合格 | 直接作为产品不合格的事实依据 |
| 被法律、法规、规章引用 | 经上位规范取得约束力 | 违反的是**法定要求** | 条文与标准**两个都引** |
| 合同、订单、技术附件、招标文件约定 | 约定效力，与推荐性／团标身份无关 | 违反的是**合同义务** | 回到条款，标准只是履行标准 |
| 单纯推荐性（GB/T、行标、团标） | 自愿采用 | 只能证明惯例或过错 | 不能单独定“违法” |

两条记牢：

- **标准能证明技术合格与否，不能证明法律上合法与否；符合标准也不当然免责。**
- **“法定要求”和“合同义务”是两条救济路径**，别混成一句“具有强制约束力”。

合同约定低于强制性标准的条款，**可能被认定无效或不能履行**，但要回到效力性强制规定的判断上具体论证；不要写成“一律无效”。

## 上位法怎么找（引致条款与位阶）

标准本身不告诉你“谁在引用它”。先找引致条款：在法律、行政法规、规章中检索业务关键词（“消防验收”“数据安全”“医疗器械”），定位“应当符合国家规定的……标准”“按照国务院 XX 部门制定的技术规范执行”这类条文，记下主管部门与标准类型，再去对应平台把抽象条款落成具体标准号。

位阶速查（2023 年立法法修改后）：

宪法 → 法律 → 行政法规 → **监察法规** → 地方性法规 → 规章（部门规章、地方政府规章）。

- 监察法规是 2023 年修法新增，涉监察程序、职务犯罪时要用。
- **自治条例、单行条例不是普通的“第三位阶”**：可以依法对法律、行政法规作出变通规定，变通规定优先适用。遇到民族自治地方案件先查有没有变通条款。
- 规章的地位分轨：**行政诉讼**中法院参照规章；**民事、刑事**中规章不是法源，只能作为认定事实、判断过错的参考，不能直接作为裁判依据。

案例检索的定性也要准：人民法院案例库是**法官办案时的检索要求**，对律师是类案检索的应做动作，不是普遍法律义务。别写成“不检索即违法”。

## 代号速查

| 类型 | 代号 | 说明 |
|---|---|---|
| 国家标准 | GB | 强制性 |
| | GB/T | 推荐性 |
| | GB/Z | 指导性技术文件 |
| | GB 55xxx 等 | **工程建设全文强制规范**（2021 年起陆续发布），整篇强制，不是“推荐性” |
| 行业标准 | 例：JGJ（建工）、CJJ（城建）、JTG／JTS（公路／水运）、HJ（生态环境）、WS（卫生）、JR/T（金融）、JB/T（机械）、YD/T（通信）、TB（铁路）、SY（石油天然气）、DL（电力）、HG（化工）、QB（轻工）、FZ（纺织）、NY（农业）、SL（水利） | 由国务院有关行政主管部门制定、报国务院标准化行政主管部门备案；**2018 年标准化法后，行业标准一律为推荐性**，`/T` 后缀即推荐性标识。具体代号以平台显示为准 |
| 地方标准 | DB + 行政区划代码 | 北京为 DB11；一般推荐性，环保等领域存在严于国标的强制性地方排放标准 |
| 团体标准 | T/团体代号 顺序号—年份，如 T/CESA、T/CCFA | 学会、协会、商会、联合会、产业技术联盟等制定 |
| **企业标准** | Q/… | 企业自行制定并**自我声明公开**，是产品实际执行标准的主要来源 |
| 国际／国外 | ISO、IEC、EN、ASTM、JIS 等 | 涉外合同、进口设备、认证采信时用；不当然在我国境内有强制力 |
| 军用／涉密 | GJB 等 | 公开渠道通常查不到，**查不到不等于不存在**，涉军涉密项目单列 |

**行业标准一律推荐性**这一条很关键：它决定了“违反行标”不当然等于违法，通常要落到合同约定或过错认定上。

## 检索五步（按顺序，不跳步）

1. **核效力**：全国标准信息公共服务平台 `std.samr.gov.cn` —— 国标、行标、地标、团标统一查，核**现行／即将实施／废止**及代替关系。
2. **取全文**：综合平台没有全文时去归口部委平台，或去国家标准全文公开系统 `openstd.samr.gov.cn`（免费公开强制性国标与推荐性国标，部分行标只到题录）：
   - 住建／工程：住房和城乡建设部 → 工程建设标准化信息网（JGJ、CJJ 与工程建设强制规范）
   - 生态环境：生态环境部 → 生态环境标准检索平台（HJ 系列，官方免费 PDF）
   - 卫生健康：国家卫健委 → 卫生健康标准网（WS 系列）
   - 金融：中国人民银行 → 金融标准全文公开系统 `cfstc.pbc.gov.cn`（JR/T 系列）
   - 工信／通信／机械／化工：工业和信息化部标准网或行业收录库
3. **查团标**：全国团体标准信息平台 `www.ttbz.org.cn` —— 按标准号、名称、社会团体名称检索，核该团体是否具备资格、标准是否已**自我声明公开**。只有题录时，去发布团体官网或官方公众号的“标准工作／通知公告”找原文与附件。
4. **查企标**：企业标准信息公共服务平台 `www.qybz.org.cn` —— 查企业自我声明公开的执行标准，是产品质量争议里最容易被忽略的一环（产品标称执行 Q/ 标准的，先查这份声明）。
5. **查司法适用**：用裁判文书与商业库看法院怎么用这条标准。**“本院认为”段落限定检索只有商业库支持，裁判文书网不提供**，别让读者白试。

检索留痕：平台、检索式、检索日期、命中条目、实际打开范围、失败原因。平台限流或维护时写明，换入口再试一次。

## 状态与版本（术语要标来源）

标准领域的**官方口径**只有三态：`现行` ／ `即将实施` ／ `废止`，被代替的写明代替它的标准号。

`部分失效`、`已被修改` 是**商业库口径**，使用时注明“据 XX 库标注”，不要当成官方状态。

引用必须四项齐全：`标准号含年份`（年份是**版本**，同名不同年可能实质不同）＋`状态`＋`实施日期`＋`查询日期`。

行为时点适用当时有效的版本，不用最新版套旧行为。合同约定了旧版而新版已实施时，先看约定，再核是否存在强制适用要求，把理由写出来。团体标准设有复审周期，是否继续有效以平台标注为准。

## 引用的正确写法

> 《XX技术规范》（GB/T XXXXX—20XX）第 X.X 条〔S-01｜官方平台｜状态：现行｜查询 2026-11-08〕

- 标准号＋年份＋名称＋条款号，缺一不可；
- 标准全文有版权，**不整篇复制**，只摘必要条款并标条款号；摘录、定位、回读与法条同一套规则（见 [citation.md](citation.md)），编号用 `S-`。

## 在业务中的用法

- **诉讼**：作为质量不符、行业惯例、过错或减损义务的依据。质证重点：版本是否适用、是否强制、是否已被代替、适用范围是否覆盖本案产品。**“不符合标准”的结论必须落到具体检测方法条款**，只引技术要求不引试验方法，举证链是断的。
- **合同**：区分“约定标准”与“法定标准”，检验条款写清以哪一版、哪一条验收；招标文件引用标准时核对是否与现行版本一致。
- **尽调／合规**：查资质与标准符合性、抽检与处罚记录；强制性标准是合规底线，不能靠“行业普遍这样”抗辩。
- **涉外**：合同约定 ISO／EN／ASTM 时，同时确认我国强制性标准是否另有要求，两者冲突时不得以合同降低法定底线；涉及通信、汽车等领域的**标准必要专利**，单独核许可与 FRAND 承诺。
- **不要做**：拿推荐性标准当强制规范指控违法；用已废止标准论证；用标准替代法律依据；把“符合标准”写成“无任何责任”；把查不到的 GJB／涉密标准写成“不存在”。

## 自检

标准性质（强制／推荐／团标／企标）说清了吗；状态与版本年份核过吗；状态术语标了是官方还是商业库口径吗；强制性与合同约定分开写了吗；条文与标准双引了吗；结论落到检测方法条款了吗；全文来源可定位吗；没有整篇复制吗；查询日期写了吗。
