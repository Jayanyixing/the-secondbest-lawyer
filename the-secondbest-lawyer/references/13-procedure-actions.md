# 13 程序动作与材料清单（立案→保全→审理→上诉→执行）

通用规则见主 `SKILL.md`；期限口径见 [09](09-case-operations.md)；证据整理见 [04](04-evidence-trial.md)。

本模块只列**要做什么、带什么、留什么凭据**，不写具体天数与金额——那些一律现场核规则原文。

## 立案

| 动作 | 材料 | 凭据 |
|---|---|---|
| 定管辖 | 按 02 的五步走完（级别→地域→专属→协议→移送） | 管辖依据截图或条文 |
| 主体材料 | 营业执照／身份证、法定代表人身份证明、授权委托书、律所函、执业证 | 材料清单核对表 |
| 起诉状 | 份数＝被告数＋法院一份；签名或盖章 | 提交回执／线上提交截图 |
| 证据 | 证据目录、证据副本（份数同起诉状）、原件备查 | 收件回执 |
| 送达地址 | 送达地址确认书、电子送达同意书（如适用） | 立案受理通知 |
| 费用 | 诉讼费预交；申请缓交、减交、免交的另附材料 | 缴费凭证 |

**立案后立刻做**：记案号、承办法官与书记员、缴费期限、举证期限起算日，全部进 09 的台账。

## 保全

| 动作 | 要点 |
|---|---|
| 申请 | 写明请求、范围、紧迫性；超标的额可能构成错误保全 |
| 担保 | 现金／保函／保全责任险，比例按承办法院要求核（见 [07](07-assets-enforcement.md)） |
| 财产线索 | 权属、账号、地址要能落到具体标的；线索不等于已查明 |
| 回执 | 裁定书、查封冻结通知、协助执行回执——没有回执不写“已冻结” |
| 后续 | 保全期限与续封、败诉后的解除与赔偿风险 |

## 审前

- **举证期限**：起算日与届满日入台账，申请延长的书面留痕；
- **证据交换**：按 04 的编号体系提交，交换后更新质证意见；
- **调查取证／鉴定**：申请事项写到可执行的程度（查什么、在哪、由谁保管），鉴定申请写清鉴定事项与检材；
- **程序性申请**：管辖异议、追加当事人、反诉、中止审理，各自有条件与时限，先核规则再提；
- **证人出庭**：申请、通知、到庭安排、询问提纲。

## 庭审

| 环节 | 准备 |
|---|---|
| 庭前 | 传票核对（时间、法庭、线上线下）、原件、授权、证人 |
| 法庭调查 | 举证说明按证据编号；质证对应三性与证明力（04） |
| 辩论 | 争点逐项回应，不在庭上首次提出新依据 |
| 笔录 | 逐页核对，重点核对自己陈述与对方承认的部分再签 |
| 庭后 | 代理意见补充、调解意向、下次开庭时间入台账 |

## 上诉与再审

- 先核**上诉期限**的起算凭据（送达回证／电子送达记录）与末日规则，按 09 三档输出；
- 上诉状份数＝对方当事人数＋法院；经原审法院递交或按法院要求线上提交；
- 上诉费预交与减缓免；
- 再审与检察监督另有一套条件与时限，不套用上诉规则。

## 执行

| 阶段 | 动作 | 凭据 |
|---|---|---|
| 申请执行 | 执行申请书、生效证明、身份材料、财产线索 | 立案回执、执行案号 |
| 财产报告 | 申请法院责令被执行人报告财产 | 报告令、报告副本 |
| 查控 | 申请网络查控（银行、不动产、车辆、证券、网络资金） | 查控反馈 |
| 施压 | 限制高消费、纳入失信名单、限制出境——各自有条件，逐项核 | 决定书 |
| 终本 | 穷尽措施后可终本；终本不等于债权消灭 | 终本裁定 |
| 恢复 | 发现新财产线索可申请恢复执行 | 恢复立案回执 |
| 救济 | 执行异议、复议、案外人异议、追加被执行人——分别核条件与时限 | 裁定书 |
| 分配 | 参与分配、优先权、执行顺序 | 分配方案 |

**执行阶段的常见错误**：把“已申请”说成“已执行”；把“已查封”说成“可回款”；把“终本”说成“结案”。

## 归档与结案

卷宗目录（按所内规范）＋结案报告（见 [11](11-client-practice.md)）＋退费与票据＋复盘要点入卡片库（见 `tools/lawdb.py card`）。

## 紧急模式（材料少、时间紧时）

开庭前一天、当事人只有几张照片、明天要交材料——按这个顺序交付，不追求完整：

1. **前 5 行**：能不能做、最紧的期限、最大缺口；
2. **今天必须做的 3 件事**（谁做、几点前）；
3. **最小可用稿**：起诉状／答辩状骨架＋证据目录，可提交但标“待补”；
4. **明确写出**：哪些结论缺材料支撑，哪些证据必须明天补。

宁可交一份标满“待补”的骨架，也不要为了完整而把缺口填成结论。

## 自检

每个动作有对应凭据吗；期限有起算来源吗；材料份数按当事人数算了吗；保全与执行的状态（申请／裁定／回执／终本）分清了吗；紧急模式下有没有为了完整而编内容。
