# 案例检索接入与降级

## 按实际可用的渠道检索

| 情况 | 本轮做法 |
|---|---|
| 可查询公开来源 | 查指导性或入库参考案例、普通裁判文书及后续裁判。访问受限时换可读的官方来源，继续使用下方已获授权的渠道。 |
| 本会话可用已授权的北大法宝或威科先行 MCP | 直接用对应案例工具按案号、标题或脱敏争点查询。按返回内容区分全文、节选、摘要及原文链接。 |
| 只有会员网页 | 优先请用户用自己的权限检索并导出必要文书。用户授权、客户端能访问指定已登录会话且平台允许辅助浏览时，可在该会话内检索；登录和验证由用户处理。 |
| 已收到用户获准提供的资料 | 直接按案号归并结果、阅读文书并核对相关段落。PDF、Word、可授权分享的原文链接或必要摘录可供分析；Excel/CSV 列表用于筛选并指出要补的全文。 |
| 没有可读正文 | 交付两至三组可复制检索词及筛选条件，列出已查范围、候选和补件要求。搜索摘要只列入待取正文的线索。 |

从案号精确定位或争点检索入手。争点检索给出案由、要件、裁判理由关键词、地域、法院级别、年份和审级，分别找支持及不利案例。例如付款争议可用“买卖合同纠纷＋付款条件＋验收”及“买卖合同纠纷＋逾期验收＋视为验收”，再按目标审理法院、年代和程序筛选。把组合词和筛选项分别列出，用户可按平台语法粘贴。检索对外只发脱敏争点或必要案号。对会员库全文、案卷和客户材料，先核对订阅条款与律所的数据处理要求，再按许可使用或传入获准的处理环境。

## 会员和接口接入

- 用户要首次配置、换账号或排查连接时，读[两家 MCP 的授权和配置步骤](case-mcp-setup.md)。核对**案例套餐、额度、正文权限及导出许可**。网页会员与接口权限分别确认。用户在客户端完成授权。
- 用户要求查案例时，检查当前会话实际可调用的工具。威科先行可识别 `wk-case-search` 或已配置的 `wk-mcp`，有案号或明确关键词时用 `search_case_keyword`，需按争点找类案时用 `search_case`。北大法宝优先识别 `pkulaw-case-keyword` 或客户端中同一官方服务下的司法案例检索工具。按客户端暴露的工具说明和入参执行，可用时选案号或精确标题字段，或用明确关键词。服务别名不同则按供应商和工具说明识别。
- 指定了供应商就使用该供应商。未指定时先用当前获准且符合查询条件的一家；需要补覆盖并符合用户授权时，再用另一家。避免将同一查询无条件发送给两家或重复扣用额度。只有用户要求配置时才引导添加连接。授权与实际查询成功分开记录。
- 遇到工具未加载、认证失败、无案例权限、计费未获授权、配额耗尽或连接失败时结束该渠道，直接使用本轮已提供的判决书。没有附件时请用户在授权平台导出允许使用的 PDF、Word 或必要摘录，并给出所需字段、检索词及筛选条件。仅返回列表或摘要、链接无法打开时，同样请求相应判决正文。按文件、页段定位并记录读取范围，清楚标明无法确认的生效状态和官方复核情况。
- 凭证由用户或管理员在客户端的授权流程或受保护配置中管理。不要向用户索要粘贴密码、验证码、Token 或 Cookie，不将凭证写入 Skill、对话、日志或仓库。仅按平台允许的权限使用访问方式，不规避付费、验证或访问频率限制。

- [人民法院案例库使用帮助](https://rmfyalk.court.gov.cn/helper.html)说明高级筛选、全文查看和下载操作。

## 交付时怎样标记来源

- 在每条案例结果旁写明案名、案号或官方入库编号、法院、裁判日期、来源平台及实际阅读范围。在线来源给出指向该文书的链接和裁判理由所在段落或小节。导出件给出文件名及页码；没有固定页码时给出节标题和可检索的段落起始文字。会员链接标明访问条件并去掉凭证参数。案号未公开时如实标明。检索结果与实读文书无法匹配、只有摘要或链接打不开且无可定位导出件时，只列为待核线索，不能用来支撑裁判观点。
- 分别写明“已读官方裁判全文”“已读商业库所载裁判全文”“已读用户提供的全文或节选”或“仅线索”，再注明官方复核结果、生效及后续裁判状态。已有商业库全文而官网未能核对时，可作带来源和限制的分析。用于正式文书前提示承办律师复核关键引文和裁判状态。
- 输出相似事实、决定性差异、裁判理由及对本案的利弊。按实际内容定位引文，页面打不开或只返回摘要时不给出假定的裁判理由。
