# 案例检索接入与降级

引用登记与状态词表以 [citation.md](citation.md) 为准；本文件只管“这一轮从哪拿案例、拿不到怎么办”。

## 按可用渠道选路

| 情况 | 本轮做法 |
|---|---|
| 公开来源可查 | 查人民法院案例库、裁判文书网、法院公告及后续裁判；同时找不利案例 |
| 本会话有已授权的北大法宝／威科先行工具 | 按案号、标题或脱敏争点检索；按返回内容区分全文／节选／摘要／链接 |
| 只有会员网页 | 请用户用自己权限检索并导出必要文书；用户明确授权且平台允许时，可在已登录会话内辅助检索，登录与验证由用户完成 |
| 已收到用户获准提供的材料 | 按案号归并，读原文，标页码或小节后引用 |
| 没有可读正文 | 交 2–3 组可复制检索式与筛选条件 + 待取正文表，不猜裁判理由 |

## 检索式怎么给

按「案由 + 要件事实 + 裁判理由关键词 + 地域 + 法院层级 + 年份 + 审级」组合，同义表述至少两组，分别找支持与不利。示例结构（词表按具体争点替换）：`买卖合同纠纷 + 付款条件 + 验收`、`买卖合同纠纷 + 逾期验收 + 视为验收`。组合词与筛选项分列，用户可直接粘贴。

对外只发脱敏争点或必要案号；会员库全文、案卷与客户材料先核对订阅条款与所内数据处理要求。

## 工具识别

- 威科先行：可识别 `wk-case-search` 或已配置的 `wk-mcp`；有案号或明确关键词时用关键词检索，按争点找类案时用类案检索。
- 北大法宝：优先识别 `pkulaw-case-keyword` 或客户端中同一官方服务下的司法案例检索工具。
- 别名不同时按供应商与工具说明识别，不硬套工具名。

指定了供应商就用该家；未指定时先用当前获准且符合条件的一家，需要补覆盖且授权允许时再用另一家。避免同一查询无条件发两家、重复扣额度。**只有用户要求配置时才引导添加连接。**

## 失败处理

工具未加载、认证失败、无案例权限、计费未授权、配额耗尽、连接失败：结束该渠道，直接用本轮已提供的判决书。没有附件时请用户在授权平台导出允许使用的 PDF／Word／必要摘录，并说明需要的字段、检索词与筛选条件。只返回列表或摘要、链接打不开时，同样请求正文。

失败**不重试、不换关键词反复试探**，一次失败即降级并在结论旁写明。

## 凭证

凭证由用户或管理员在客户端授权流程或受保护配置中管理。不索要粘贴密码、验证码、Token、Cookie，不写入技能、对话、日志、仓库。不规避付费、验证与频率限制。

## 交付时怎么标来源

每条案例结果旁写：案名、案号或入库编号、法院、裁判日期、审级、来源渠道、实际读取范围、定位（段落／小节／页码）、官方复核状态、生效状态。会员链接去掉凭证参数。

分别写清：`已读官方裁判全文` ／ `已读商业库所载裁判全文` ／ `已读用户提供的全文或节选` ／ `仅摘要` ／ `仅标题`。后两者只能进待取正文表。

已有商业库全文而官网未核时，可作带来源与限制的分析，并在正式文书使用前提示承办律师复核关键引文与裁判状态。输出必须包含：相似事实、决定性差异、裁判理由、对本案的利弊。
