# 引用与可追溯（本技能最高优先级规则）

> 本文件优先于其他模块的行文习惯。凡进入交付物的法条、案例、机关与主体信息，**必须先有底稿条目，再以固定格式引用**。没有底稿条目的一律不准进正文。

## 引用五则

1. **无底稿，不进正文。** 先登记，后引用；顺序不可颠倒。
2. **四要素齐全。** 案例：完整案号 + 法院全称 + 裁判日期 + 审级（＋二审／再审情况）。规范：全称 + 条款 + 制定机关 + 施行日期（＋最新修订）。
3. **必带摘录。** 每条用于支撑结论的依据，底稿里必须存一句**逐字抄录的原文**（8–60 字），不得写概述。摘录是“我确实读过”的最低证据，也是人眼唯一能快速验伪的东西。
4. **交付前回读。** 凡进了结论、裁判理由或引用包的条目，交付前重新打开来源，按摘录逐字比对一遍；回读只问「本会话是否真的读到正文」，不限来源；回读不一致，立即降级，不得保留原引用。
5. **一依据一出处一定位。** 每条依据都要能落到具体页码、段落、小节或时间点；落不到就降级为“待取正文”，不得用来支撑结论。

做不到第 2–5 条时，标准动作是**写清缺什么、怎么补**，而不是把缺口填成内容。

**只看摘要或标题时，不要写摘录**——因为摘录必须是原文。没有原文，这一条就只能进待取正文表。

## 引用底稿

交付物附一份底稿，正文每个引用都指回这里。编号固定前缀：`N-` 规范、`C-` 案例、`S-` 标准、`M-` 机关／联络／主体信息。

| 字段 | 要求 |
|---|---|
| 编号 | N-01 / C-01 / S-01 / M-01，正文以 `[C-01]` 标注 |
| 类型 | 法律／行政法规／司法解释／地方性法规／规章／规范性文件／法院文件；指导性案例／入库参考案例／典型案例／普通裁判／仲裁裁决 |
| 名称与四要素 | 规范全称、条款；案例案名、完整案号、法院、裁判日期、审级 |
| 来源渠道 | 见下方封闭词表 |
| 出处 | 具体原文链接（非首页、非搜索页）；或导出文件名 + 页码／小节标题；或“用户口述” |
| 定位 | 页码、段落、小节标题或音视频时间点；页码范围写“第 X–Y 页” |
| 读取范围 | 见下方封闭词表 |
| **摘录** | **逐字抄录的原文 8–60 字，与“定位”指向同一处；概述不算** |
| **回读** | `已回读（日期）` ／ `未回读`；本会话实际打开并读到正文即算，来源不限 |
| 官方复核 | 见下方封闭词表 |
| **规范效力**（规范类必填） | 见下方封闭词表；案例不填此栏，用「生效与后续」 |
| **适用时点**（规范类必填） | 行为时点、程序时点、适用版本、依据（含过渡条款） |
| 生效与后续 | 见下方封闭词表 |
| 登记日期 | 本次实际读取的日期，不与页面发布日期混同 |

一页底稿表即可。条目多时按类型分表，编号连续。

**最简可用形态**（不必另存文件，直接附在交付物末尾，`tools/citation_lint.py` 会自动识别）：

| 编号 | 摘录 | 回读状态 |
|---|---|---|
| N-01《中华人民共和国劳动合同法》第三十八条第一款第（三）项 | 未依法为劳动者缴纳社会保险费的 | 摘录来自本地库 |

编号写在首列即可（`N-01` 或 `〔N-01〕` 都认）；案例写 `C-01 指导案例190号` 或 `C-01（2023）京03民终1234号`。字段齐全是加分项——缺字段只做编号与摘录校验，缺字段本身不会阻断交付，但没有摘录会。

## 封闭词表（只准用这几个词，不自造近义词）

**读取范围**：`全文` ／ `节选（第X–Y页｜第X小节）` ／ `摘要` ／ `标题` ／ `未读`

**来源渠道**：`官方页面` ／ `商业库` ／ `用户提供导出件` ／ `用户口述` ／ `未取得`

**回读**：`已回读（YYYY-MM-DD）` ／ `未回读`。回读只记录「本会话有没有真读到正文、摘录对不对得上」，官方性不在此栏判断

**官方复核**：`已核（与官方原文一致）` ／ `未核（仅商业库或转载）` ／ `不适用（用户材料，不涉官方）`。白名单只约束这一栏：只有官方站点与用户原件能记「已核」，商业库与转载件一律「未核」

**生效与后续**（案例用）：`已确认生效` ／ `未确认` ／ `存在后续程序（列明审级与结果）`

**规范效力**（规范用）：`现行有效` ／ `已修改（列修订时间）` ／ `已废止（列废止日与替代规范）` ／ `未施行（列施行日）` ／ `未确认`

**引用状态（写在正文或表内）**：`可直接引用` ／ `仅作背景` ／ `待取正文` ／ `摘录来自本地库`

词表之外的混用（如“已核对原文”“已读官方裁判全文”“待核线索”“检索受限”）视为状态不明，等同于未核验。

## 正文引用格式

规范：
> 《中华人民共和国民法典》第 X 条第 X 款〔N-03｜官方页面｜已核｜回读 2026-11-08〕

案例：
> （20XX）京 XX 民终 XX 号，北京市第 X 中级人民法院，20XX-XX-XX，二审〔C-04｜商业库｜全文｜官方复核：未核｜生效：未确认〕

首次出现写全，后文用短号 `[C-04]`。同一段落连续引用多个依据时，每个依据单独给号，不合并成一个链接。

## 回读校验怎么做（交付前必做）

对每一条进了**结论／裁判理由／引用包**的条目：

1. 重新打开本次实际读取的来源（官方页面、已授权商业库工具返回、用户导出件或案卷），不用缓存、不复用上次的阅读记忆；
2. 找到“定位”指向的那一处；
3. 把底稿里的摘录与原文**逐字**比一遍，包括标点、否定词、“不／未／无”；
4. 一致 → 回读字段写 `已回读（日期）`；不一致或找不到 → 该条降为 `待取正文`，正文里的引用同步删掉或改写；
5. 回读只做一次不算完成：交付物改版后，受影响条目重新回读。

摘录与原文差一个字也可能是反向结论（“未支付”与“已支付”），这类差异必须当作硬错误处理。

## 禁止模式（出现一条即不合格）

- 只给标题、公众号文章、律所推文、百科、问答或搜索结果页链接；
- 一个链接同时支撑两个以上不同案例；
- 把转载、汇编、二次解读当作独立案例；
- “某法院认为……”“司法实践普遍认为……”“有判例支持……”而无案号；
- 用“根据相关规定”“依照有关法律”替代具体条款；
- 只读摘要或要旨，却写出裁判理由、合议庭观点或判决主文；
- **摘录写成概述、改写或拼接**（如把两句合成一句、把“本院不予支持”写成“法院认为无理由”）；
- **摘录只写“本院认为”“依照法律规定”这类任何判决都有的套话**——它不能证明你读的是这一份；
- 编造或“合理推测”案号、入库编号、指导案例编号、文号、条号；
- 把未生效一审判决说成生效裁判，或隐去对己方不利的后续改判；
- 用检索命中数反推“此类案件胜诉率”。

## 降级路径（读不到正文时）

输出一张 `待取正文` 表：案号或标题｜来源平台｜已知信息｜需要补的正文段落｜取用方式（用户自己导出／授权商业库／申请查阅）。附两至三组可直接粘贴的检索式与筛选条件。这张表可以进交付物，但**不得进结论段**，也不得在摘要里写“已核”。

**离线模式（无法联网回读时）**：本地法条库与卡片库可以直接引用，引用状态写 `摘录来自本地库`（已入词表），不得写成 `已核` 或 `已回读`。

离线稿的定性是**草稿，不可作为定稿**：标题必须带 `〔草稿〕`，不得写「可交付」「可直接使用」。此时交付物**首页必须写一句**：

> 本稿未经联网回读：引用均取自本地库摘录，回读率 0%，全部条目待回读。

并在文末给出待回读清单（条目编号＋建议核对的官方来源）。用户若要求「直接能用的定稿」，先说明这一步没做，不能含糊过去。

机械校验用 `--mode offline`：R15 降为警告，强制检查首页声明与待回读清单，且输出里不出现「可交付」。


## 回读与官方复核（两件事，别混）

**回读**问的是「本会话有没有真的读到正文、摘录对不对得上」。任何来源都可以：官方页面、已授权商业库工具返回的正文、用户提供的导出件或原件。回读比对的是**摘录与所读页面**，不是与官方原件。

**官方复核**问的是「这条依据的官方原文有没有亲自核过」。只有下列官方站点与用户原件能记「已核」：

- `court.gov.cn`（最高人民法院官网案例与发布稿）、`rmfyalk.court.gov.cn`（人民法院案例库）
- `wenshu.court.gov.cn`（中国裁判文书网）
- `npc.gov.cn`（人大网当期法规页；`flk.npc.gov.cn` 的 API 多为空壳，别当正文）
- `www.gov.cn/zhengce/xxgk/gjgzk/`（国家规章库，部门规章与地方政府规章）
- `www.bjrd.gov.cn`（北京市人大）、`beijing.gov.cn`（北京市政府门户，地方性法规、规章、规范性文件）
- `bjgy.bjcourt.gov.cn`（北京法院网）、`www.bjcourt.gov.cn`（北京法院审判信息网）
- `www.spp.gov.cn`（最高人民检察院官网，检察指导性案例、抗诉与检察建议发布稿）

上述两站经用户于 2026-11-09 确认官方身份。**裸域不是入口**：`bjcourt.gov.cn`、`spp.gov.cn` 只作子域归属判断，引用须写具体站点与原文路径；出处只有主机名或根路径（`https://www.spp.gov.cn/`、`https://bjcourt.gov.cn`）按「出处不具体」报 R2。

**用户件分两种，别混**：

- **官方件的本地副本或导出件**（从上述站点下载、用户自己保存的 PDF/Word）：只有当底稿写明来源是上述官方站点时，才可记 `已核（与官方原文一致）`；来源说不清，一律 `未核（仅商业库或转载）`。

  写法示例（三段缺一不可）：

  ```
  渠道：导出
  出处：https://www.court.gov.cn/zixun/xiangqing/467931.html 下载的判决书 PDF（2024-11-01 导出）
  官方复核：已核（与官方原文一致）
  ```

  出处里必须出现白名单站点的完整链接；只写「判决书.pdf」「用户提供」「第 3 页」都不算，校验器（R18）会报错。从商业库导出的文件按商业库处理，记 `未核（仅商业库或转载）`。
- **用户自有材料**（合同、案卷、当事人提供的文件、工作底稿）：记 `不适用（用户材料，不涉官方）`，永远不得记「已核」——没有官方原文可核，硬写已核就是伪造。

商业库（北大法宝、威科先行）、律所数据库、公众号与门户转载件：回读可以记「已回读」，官方复核只能记 `未核（仅商业库或转载）`、不适用或留空；写「已核」「已比对一致」「已验证」「基本核实」「一致」等任何别的说法都由校验器报错（R18）。

`zh.wikisource.org` 属转载，版本不可靠，只能记「未核」。

**交付口径**：交付首页写明「官方复核未核 N 条」；正式诉讼材料中，这些条目单独进「提交前须核」清单。这是**警告**，不是错误——不因为拿不到官方原文就拒绝交付，但也不许把商业库正文写成「已核」。

「提交前须核」清单固定四列，第四列只作记录，**不影响**首页「官方复核未核 N 条」的计数：

| 编号 | 待核事项（缺什么） | 建议核对入口 | 核对备注（人工填，可不填） |
|---|---|---|---|
| N-01 | 官方原文未核，摘录取自商业库 | 发布机关官网（法规库） | |
| C-01 | 裁判文书只见转载件，未见官方发布稿 | 人民法院案例库或裁判文书网 | |

核对入口仅供人工核对，**不改变底稿的官方复核状态**；只有按三段式写法补上官方链接、并把官方复核改成「已核（与官方原文一致）」，才记已核。

「建议核对入口」按条目类型预置，别写「网上查」这种空话：

| 条目类型 | 建议核对入口 |
|---|---|
| 北京法院文件（判决、裁定、会议纪要） | 发布机关官网：`bjcourt.gov.cn`、`beijing.gov.cn` |
| 检察文件（起诉书、抗诉书、检察建议、指导性案例） | 发布机关官网：最高检`www.spp.gov.cn`、北京市检`www.bjjc.gov.cn` |
| 商业库案例（北大法宝、威科先行等） | 人民法院案例库（`rmfyalk.court.gov.cn`）或裁判文书网（`wenshu.court.gov.cn`） |
| 行政法规、部门规章 | 国家规章库（`www.gov.cn/zhengce/xxgk/gjgzk/`） |
| 法律、司法解释 | 人大网（`npc.gov.cn`）、`flk.npc.gov.cn` 详情页 |
| 地方性法规、地方政府规章（北京） | `www.bjrd.gov.cn`、`beijing.gov.cn` |

每次回读在底稿后追加一行记录，缺一行就等于没回读：

| 编号 | 回读来源（URL 或文件名） | 回读日期 | 摘录比对 | 结论 |
|---|---|---|---|---|
| N-03 | https://www.court.gov.cn/…/467931.html | 2026-11-09 | 一致 | 已回读 |
| C-01 | 北大法宝导出.pdf | 2026-11-09 | 页面无该段 | 降为待取正文 |

- 「摘录比对」只写三种结果：`一致`／`不一致（差异：…）`／`页面无该段`。
- **回读日期只到日**，且必须来自工具返回（页面日期、文件修改时间、导出记录）或用户给定；没有时钟工具就不填时刻，不写「上午／下午／刚刚」，不编造。取不到日期写 `已回读（日期待补）`，不得留空也不得推测。
- 同一上下文里完成的回读属**自查**性质；独立回读须按 [SKILL.md](../SKILL.md) 的独立复核流程，另起上下文，不得自行改写成「已复核」。
- 回读失败就降级，不要换一个近似页面凑数；同一来源两次失败即停，写待取正文。
- **已知情形**：`www.spp.gov.cn`、`bjgy.bjcourt.gov.cn`、`www.bjcourt.gov.cn` 对脚本常返回 502、403 或安全检查页，这不是「库内没有」。按「同一 URL 两次失败即停」降为待取正文，不换镜像、不换近似页面；提示用户在浏览器打开原文并导出，再按三段式登记（渠道：导出 ＋ 出处：官方链接 ＋ 官方复核：已核（与官方原文一致））。

## 交付前机械校验

正式文书、法律意见、尽调、标书交付前运行 `tools/citation_lint.py`：

| 规则 | 检查内容 |
|---|---|
| R1 | 正文案号是否都在底稿；有无占位案号 |
| R2 | 底稿是否缺来源／定位／读取范围／复核状态 |
| R3 | 摘要、标题级条目是否被用来支撑正文 |
| R4 | 未确认生效却写成生效判决 |
| R5 | 期限日期是否缺 `已核`／`〔假设〕`／`待核` 标签 |
| R6 | 绝对化措辞 |
| R7 | 无具体依据的引用 |
| R8 | 引用了不存在的底稿编号 |
| R9 | 自查模式却写“已复核” |
| R10 | 底稿条目未被引用（可能多余） |
| **R11** | **支撑结论的条目缺摘录** |
| **R12** | **摘录不在引用处附近**：在全文中别处能找到→警告（可能摘录与结论不是同一段）；全文都找不到→错误 |
| **R13** | **摘录过短或全是套话**（无法证伪） |
| **R14** | **摘录与引用处不对应**（同一摘录被多个不同结论复用；普通模式警告，`--strict` 下为错误） |
| **R15** | **用于结论的条目未回读**；回读日期缺日期（警告）或晚于运行当天（错误） |
| **R16** | **规范类条目缺「规范效力」或「适用时点」**（警告）；规范效力为 `未确认` 却用于结论（错误）。两条独立判定，缺字段不会屏蔽错误；词表外的效力写法按 `未确认` 处理；内联底稿缺这一栏只出一条汇总提示（严格模式升为警告），不逐条刷屏；`--strict` 下，用于结论却未登记「规范效力」也报错 |
**官方复核栏的取值规则（默认拒绝）**：只有词表内写法算数——`verified`／`已核`／`已核实`／`官方已核`／`已核（与官方原文一致）`记「已核」，`unverified`／`未核`／`未核（仅商业库或转载）`／`未经核实`／`未能核实`／`尚未核`记「未核」，`na`／`不适用`记「不适用」。其余任何带「核」字的写法（如「未经官方核实」「尚未经官方核对」「未能与官方原文核对」「未完成核对」「核对中」「待核」「基本核实」）一律按「未核」处理，并出一条提示「官方复核写法不在词表内，已按未核处理」。**不认识的写法永远不升级成「已核」。**

| **R17** | **离线稿形态不合规**：缺 `〔草稿〕`／缺首页「未经联网回读」声明／缺待回读清单／肯定地声称「可交付」「已核实」（错误）。否定只在同一分句内算数：「不是可交付稿」「无一条已核实」通过，「未经回读，但引用均已核实」报错 |
| **R18** | **渠道与出处/官方复核不符**：①渠道写「官方」但出处域名不在官方白名单（`court.gov.cn`／`npc.gov.cn`／`www.gov.cn/zhengce/xxgk/gjgzk/`／`bjrd.gov.cn`／`beijing.gov.cn`／`bjcourt.gov.cn`／`spp.gov.cn`；主机名须**等于**白名单域名或以「.白名单域名」结尾，不认裸 `gov.cn`，`court.gov.cn.evil.com`、`pkulaw.com/redirect?u=court.gov.cn` 都算不合规）——用户导出件请把渠道写成「导出」；②非官方渠道的官方复核栏只接受未核词表、不适用或留空（官方站点下载的导出件须在出处写明官方链接，才可记「已核」）；写「已比对一致」「已验证」「基本核实」「一致」等都报错；③渠道写「官方」却没有任何出处链接，同样报错 |
| **R19** | **首页计数与表格不符**：合同审查类交付（含「等级」列的风险表）中，首页声明的总数、各等级数、必改数必须等于风险表与必改清单的行数；数由表计数得出，不手填。自查模式（`--mode self`）报错，其他模式警告；首页数字解析不到时只提示。必改清单按小节标题含「必改项」或首列「必改 N」识别，风险等级取「等级与触发场景」列开头的 高／中／低 |
| **R20** | **替换条款引用不存在的编号**：替换条款里出现的「第 x.y 条」「第 x 条」必须在原合同、风险表「位置」列、编号映射表（表头含原编号／新编号／说明）或 `--contract` 指定的原合同文件中能找到；同一行替换条款里自己定义的编号不算缺。普通模式警告，`--strict` 报错。法条用汉字条号，不在此列；紧跟《…》之后的条号跳过 |
| **R21** | **无出处的法律结论**：风险表的行里出现「无效／不发生效力／不生效／可撤销／可调减」，而该分句及前一分句都没有 N-／C- 编号时提示。按分句（。；）判断，`「」`与引号内的原文不计；写了「法律判断待核（未登记依据）」的跳过。启发式，仅警告，不阻断交付 |

校验不通过不得标注为可交付。校验器只能验形式一致性——**能不能证明真伪，最终靠回读那一步和律师本人**，这一点不要自我安慰。
