# 数据供给：三层，先本地后联网

技能本身不附带数据库权限。能不能拿到原文，取决于数据从哪来。按下面三层依次取，**取到就停，不要为“更全”而跳过本地已经有的条文**。

## 三层与顺序

| 层 | 内容 | 何时用 | 代价 |
|---|---|---|---|
| **L1 本地法条库** | 官方下载的法规文件，索引成本地 SQLite | 查条文原文、条号、版本 | 一次性搭建，之后离线、毫秒级、零查询费 |
| **L2 授权检索** | 北大法宝／威科先行 MCP 或 API、官方网站在线检索 | L1 未命中；查类案、最新裁判、地方文件 | 订阅费或按量计费，受接口权限限制 |
| **L3 人工导出** | 律师在已登录平台检索后导出 PDF／Word | L1、L2 都不通 | 零成本，但要有人操作 |

判定顺序写死为：**L1 → L2 → L3 → 待取正文**。三层都没有，就出检索式与待取正文表，不猜。

## L1：本地法条库

### 为什么值得先做

- 法规总量是万条级、几十 MB，不像判例海量；
- 离线可用，不受 403、验证码、维护窗口影响；
- **天然满足引用铁律**：库里就是原文，摘录不会错一个字，引用带导入日期与哈希，回读可机器校验。

### 数据从哪来（只用官方渠道）

| 来源 | 怎么取 |
|---|---|
| 国家法律法规数据库 `flk.npc.gov.cn` | 网页检索到法规 → 用页面上的「下载」取 Word 或 HTML |
| 中国人大网 `npc.gov.cn` | 法律全文页 → 浏览器「另存为」网页 |
| 最高人民法院 `court.gov.cn`、最高检 `spp.gov.cn` | 司法解释、批复页面另存 |
| 地方人大／政府网站 | 北京地方性法规、规章、规范性文件页面另存 |
| 商业库 | 按订阅许可导出，**仅在许可范围内本地留存** |

**不做爬虫**。官方站点普遍反爬（实测 `flk` 接口已改为前端渲染、法院转载站直接 403），批量抓取既不稳定也不合规。手工下载一次，本地长期复用，才是可持续的路径。

### 怎么导入

```bash
python3 tools/lawdb.py init

python3 tools/lawdb.py import 民法典.docx \
  --name 中华人民共和国民法典 \
  --issuer 全国人民代表大会 \
  --publish 2020-05-28 --effective 2021-01-01 \
  --url https://flk.npc.gov.cn/... \
  --official-check 已核

python3 tools/lawdb.py query 违约金 调整 --limit 5
python3 tools/lawdb.py article 中华人民共和国民法典 第五百八十五条
python3 tools/lawdb.py stats
python3 tools/lawdb.py verify      # 比对磁盘文件哈希，发现变更即报警
```

支持 `.txt/.md/.html/.docx/.pdf`（pdf 需系统 `pdftotext`）。切条按「第X条」，自动挂靠最近的编／章／节，条号支持中文数字排序。

### 建议覆盖

民法典（合同编、物权编、侵权编优先）、民事诉讼法及解释、刑法及修正案、刑事诉讼法、公司法（2023 修订）、劳动合同法、行政处罚法与复议法、北京地方性法规与法院文件、常用司法解释。

### L1 命中时怎么写引用

> 《中华人民共和国民法典》第 X 条第 X 款〔N-03｜本地库｜导入 2026-11-08｜sha256 前 8 位｜官方复核：未核〕

- 从官方网页直接下载的原件，`official_check` 可填 `已核`；
- 从商业库导出的，填 `未核（仅商业库）`，正式文书使用前仍需官方核对；
- 本地库条目同样要有**摘录**（直接抄库内原文）与**回读**记录（用 `lawdb verify` 比对哈希）。

## L2：授权检索

配置见 [案例库接入](case-mcp-setup.md) 与 [接入与降级](case-access.md)。要点：

- 网页会员 ≠ 接口权限，要单独确认「案例正文可读、可导出」；
- 额度、计费口径先问清，避免一次类案检索打爆套餐；
- 一次失败即降级，不换关键词反复试探。

## L3：人工导出

律师在已登录平台按你给的检索式导出，拖进对话。要求导出的文件带：案号、法院、裁判日期、页码；你据此建底稿、写摘录、标回读。

导出件按 [citation.md](citation.md) 登记，`来源渠道` 填 `用户提供导出件`，官方复核填 `未核`，除非同时打开官方原文核对过。

## 更新节奏

- 本地库：**每季度**检查一次新法与修订；重大修法（如公司法、民诉法）施行前必须更新。
- 已导入法规被修订时：重新导入同名条目（脚本按法名覆盖），并把引用了旧条的交付物标记为需复核。
- 到期检查已并入 `MAINTENANCE.md`，用 `python3 tools/review_due.py` 提醒。

## 红线

不批量爬取官方站点；不绕过登录、验证码、付费墙；不共享商业库账号或凭证；导出的判决与法规仅在订阅许可与执业允许范围内本地留存，不对外分发。
